When Outputs Disperse, Does Epistemic Revision Follow? A Black-Box Coupling Diagnostic for Machine Collectives（当输出分散时，认识论修正会随之而来吗？机器集体的黑盒耦合诊断）

集体智能研究通常将分歧视为认识论多样性的证据：如果智能体表达不同观点，群体应保留修正能力。然而在LLM集体中，这一代理指标可能失效——智能体可以产生看似多样的论证，同时保留相同结论。本文提出"分散-修正耦合"（dispersion-revision coupling）概念：衡量干预在嵌入空间中可验证地增加集体输出分散度的同时，是否伴随真正的认识论立场修正，而非保留前提的重述。该诊断是黑盒的：仅基于生成文本操作，不对生成模型的内部表征作任何假设。两个通道独立测量：输出通道——一致性指数（CI）验证干预是否改变输出分散度；认识论通道——逐轮立场标注衡量集体是否真正修正。

作者提出CI结合元预测清晰系统（MPCS），当输出过度收敛时插入再差异化协议（RDP），作为估计该耦合机制的可复用方法。研究评估了两种配置的五智能体集体（gpt-4o-mini和gemini-2.5-flash；每种条件310对情节）。结果显示：在gpt-4o-mini上，条件性异议使错误前提恢复率提升+17.7个百分点（p<1e-6），而静态人格多样性反而损害恢复率（-8.1, p=.007）；在gemini-2.5-flash上，相同干预在可比预算下未产生增益（26.1% vs 27.1%, p=.84），尽管分散度确实下降；两种处理效应存在显著差异（z=3.79, p<.001）。机制标注显示Gemini通过框架内异议保留错误前提：94%的RDP后响应为重述而非让步（GPT为24%）。作者建议在报告准确率的同时，报告每次干预的立场转变率和前提保留率。

3. 分析工具：构建了经验树核诊断方法，总结候选诱导路径对训练样本的分组方式。当经验核秩向样本量增长且出现极小正特征值时，暴露了噪声敏感方向；在此区间，测试误差先达到峰值，随后在更大分裂候选预算下再次下降。

4. 理论预测：更深的树应在更少分裂候选数下达到该区间；更大的训练集需要更细的网格；标签噪声会使峰值更明显。

6. 结论：分裂候选缩放可作为研究GBDT的单轴容量干预手段，观察到的双重下降源于候选诱导几何与提升动力学之间的交互作用。

On the Implicit Flatness Bias of Sharpness-Aware Minimization: A Linear Stability Analysis with Quantitative Hyperparameter Bounds（关于锐度感知最小化的隐式平坦性偏好：基于线性稳定性分析的定量超参数界限）

核心观点：本文通过线性稳定性分析，首次定量揭示了Sharpness-Aware Minimization（SAM，锐度感知最小化）方法隐式偏好平坦极小值的机制，并给出了关键超参数的定量界限。

主要贡献与结论：

1. 定量稳定性界限推导：在局部线性化和梯度噪声对齐假设下，证明每个线性稳定极小值满足 λ_max ≤ ³√(bΓ/(2ρη²))，其中λ_max为Hessian最大特征值，b为批量大小，η为学习率，Γ为梯度范数上界，ρ为扰动半径。

2. 隐式平坦性偏好的定量刻画：固定其他量时，较小的批量、较大的学习率或较大的扰动半径ρ，会使线性稳定的SAM收敛到更平坦的极小值。

3. 必要权衡的揭示：ρ需足够大以促进平坦性，但又需保持局部性以维持近似精度和训练稳定性——即“稳定性-局部性”权衡。

4. 实验验证：在CIFAR-100上用ResNet-18和VGG-19进行了900个模型的受控实验，证实增大ρ与更小的最大Hessian特征值一致相关（跨不同批量和学习率设置）。

5. 方法实例化：提出TLC-SAM（Taylor-Locality Controlled SAM），根据观测到的Taylor近似误差动态调整ρ，相比固定半径SAM进一步降低了最大Hessian特征值。

意义：提供定量超参数界限和“稳定性-局部性”视角，为分析和设计SAM变体提供了理论依据。

Relational Priors as Convergence Pressure in LLM-Based Multi-Agent Systems（关系先验作为基于大语言模型的多智能体系统中的汇聚压力）

核心观点总结：

1. 研究问题：基于大语言模型的多智能体系统（LLM-MAS）通过角色、辩论协议和聚合规则设计，隐含了智能体间的社会期望（信任、挑战、服从或协作）。本文研究将智能体间关系语义显式化（即注入“关系先验”）所产生的效果。

2. 方法：采用最小化的符号网络形式化关系先验，将自然语言表述注入智能体系统提示中，同时保持任务协议不变。在公共资源治理模拟和多智能体辩论两个场景中进行验证。

3. 主要发现：关系先验主要充当“汇聚压力”——增加关系正向性会使智能体更容易协调或达成一致。该压力在效用奖励行为对齐时（如可持续资源治理、主观共识）有帮助，但不能可靠地提升准确性。

4. 关键局限：在客观问答辩论中，更高的正向性可能增加“一致性”，但“正确性条件化的一致”并未提升，某些情况下甚至下降。效果因模型骨干、关系类型和拓扑结构而异；显式中立并不等同于省略关系框架。

5. 结论与建议：关系先验不应作为LLM-MAS的默认附加组件。其更安全的用途是诊断性和任务特定性的：与无先验基线对比，在重视真理时监控正确性条件化指标，在验证不支持时省略关系层。

ContinualSkillBench: Can LLM Agents Truly Evolve Their Capabilities?（持续技能基准：LLM智能体能否真正实现能力进化？）

核心问题：现代智能体框架为大语言模型配备外部技能库以解决复杂任务，但系统能否有效进化技能、进化后的技能是否真正提升任务解决能力，仍不明确。

提出方法：作者引入ContinualSkillBench——一个面向上下文持续技能学习的动态评估框架，覆盖五个代表性领域，每个领域包含100个按难度递增排列且存在跨任务技能复用机会的相互关联子任务。

主要发现：①顺序执行普遍能提升性能，但提升幅度因模型和领域差异显著；②上下文学习在平均表现上与显式技能维护相当，说明大部分提升源于对先前上下文和反馈的适应，而非可复用的技能抽象；③显式技能仅对需要可复用程序或精确输出的任务提供选择性优势；④能力较弱的模型倾向于积累更大、更碎片化的任务特定技能集合。

结论：当前的上下文技能进化机制可支持持续适应，但在将经验稳定整合为鲁棒、可迁移的技能方面仍存在不足。

Can LLMs Test Terminal User Interfaces?（大语言模型能否测试终端用户界面？）

终端用户界面（TUI）结合了图形界面的有状态、面向屏幕行为与终端部署方式，在开发者工具中已十分普遍，但缺乏专门的测试方法。本研究调查了197个真实世界TUI应用：仅12%的测试代码实际调用界面，其中45%的测试从不发送输入，仅检查静态帧。我们将这些应用转化为一个无头基准测试集，涵盖ratatui/Rust、bubbletea/Go、textual/Python和ink/TypeScript四大框架，并将每个应用封装为可插桩的Docker镜像，记录行覆盖率、组件覆盖率、渲染终端状态及崩溃情况。在相同墙钟时间预算下，我们比较了四个前沿大语言模型与随机探索：没有模型占据主导地位。随机搜索作为时间预算基线表现强劲，但其崩溃优势源于更高的吞吐量；按单次交互计算，大语言模型引导更高效，且能独特地触达输入门控缺陷。自动推导启动输入带来最大实际收益，使原本无法启动的应用得以运行。行覆盖率对崩溃发现预测能力弱，削弱了其作为测试有效性代理指标的作用。自动化TUI测试可行但远未解决，诚实的基线比模型选择更重要。我们发布了覆盖率工具tuicov（https://github.com/tui-testing/tuicov）和测试框架tuibot（https://github.com/tui-testing/tuibot）。

Accelerating Dynamic Graph Clustering on GPU Architectures with cuGraph（利用cuGraph在GPU架构上加速动态图聚类）

核心摘要：本研究针对时序网络中的社区检测问题，通过GPU加速扩展了原本用于静态图的谱聚类和基于模块度的算法。基于NVIDIA RAPIDS生态系统，该框架支持对快照式动态图中的社区进行表征与追踪，实现方式有两种：一是采用支持多GPU的Leiden贪心优化（通过Dask进行工作负载分配），二是对对称Bethe-Hessian算子进行特征分解。主要成果：在相同工作量下，多切片模块度后端相比CPU参考实现实现了高达约三个数量级的加速（具体取决于图的密度和快照数量），同时保持与现有图分析管道的兼容性。研究在真实世界和合成数据集上验证了其适用性，有助于对网络结构属性随时间变化进行探索性分析。该能力适用于多个应用领域，包括流行病传播、金融系统、网络安全以及轨迹与移动性分析。开源发布：实现以免费开源软件形式发布，并通过NetworkX-Temporal库提供Python绑定，便于使用且无需修改现有代码即可实现零编码加速。
