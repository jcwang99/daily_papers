Markerless Pose Estimation for Resistance Training Technique Assessment（基于无标记姿态估计的抗阻训练技术评估）

核心内容：抗阻训练存在较高受伤风险，正确的动作姿势对预防损伤至关重要。实验室内的运动分析可提供定量技术评估，但不易普及。无标记姿态估计无需物理标记即可从图像或视频中推断身体关键点，是可行的替代方案。本文提出一个从普通视频中评估抗阻训练技术的姿态估计框架。

$(\text{DNN})^2$: Doubly Non-Negative Relaxations for Deep Neural Networks（$(\text{DNN})^2$：用于深度神经网络的双重非负松弛）

核心问题：现有的线性规划（LP）和半定规划（SDP）松弛方法在ReLU神经网络验证中因松弛间隙过大而给出过于保守的安全保证。完全正规划（CPP）虽能消除间隙，但求解是NP难的。

方法创新：其最廉价的易处理松弛——双重非负规划（DNN）——保留了关键约束作为SDP，但在实际规模下超出内点法的处理能力。此前Burer-Monteiro（BM）分解已被用于扩展SDP验证的可扩展性，但尚无针对更严格的DNN形式的研究成果。主要障碍在于DNN中额外的非负性约束导致最优性认证的对偶乘子非唯一，使标准认证方法失效。本文提出一种新颖的特征值最大化程序，在非唯一乘子空间中搜索有效证书（即全局最优性保证）。

实验结果：该方法 $(\text{DNN})^2$ 产生的边界始终比标准SDP方法更紧，通常接近精确解；当有效证书存在时，认证程序能确认全局最优性。

意义：这些结果是向在安全关键自主系统中部署神经网络控制器和感知模块所需的紧致、可认证且计算可扩展的验证保证迈出的关键一步。

方法创新：提出影响感知策略优化（IAPO），将每次完整的轨迹表示为带类型的影响依赖图（节点为可训练智能体动作，用户和工具观察作为证据），利用“支持-使用”和“失败-使用”结构转化为路由权重，重新分配同一轨迹级别的优势值，无需额外对比轨迹或逐步骤构建学习信号。
关键优势：直接利用已完成轨迹中信息与错误的流动结构进行信用修正，避免依赖外部对比证据；同时不损害多轮函数调用性能。
实验结果：基于Qwen3-4B和Qwen3-8B，在三个服务智能体基准（τ²-Bench、UserBench、AgentChangeBench）上显著优于多轮强化学习基线；BFCL-v4多轮评测进一步证明性能提升不牺牲函数调用能力。
研究意义：深化了对多轮用户交互中信用分配的理解，为从稀疏结果反馈训练服务智能体提供了原则性方法。

核心观点总结：

1. 问题背景：在机械可解释性中，跨整个领域发现稳定的神经元行为仍是一大挑战。现有方法多依赖实例级点估计或高计算成本流程，前者掩盖了群体层面的变异性，后者限制了领域级大规模分析的可扩展性。

From local kernels to global form: modeling the emergence of musical content（从局部核到整体形式：模拟音乐内容的涌现）

核心观点总结：本文提出一种基于观测驱动的马尔可夫模型估计机制，用于符号音乐分析。该方法通过重叠滑动窗口从单一符号序列中推导局部转移核的轨迹，而非依赖外部形式划分。作者以德彪西《Syrinx》（1913）中273个逻辑音符事件为测试对象，将常用的A-B-A'读法作为参考基准（而非真值），分别应用于绝对音高和记谱时值核的验证。

主要发现：在窗口长度L=6时，两个参考边界在两种维度下均达到Jensen-Shannon散度最大值；但时值平台的宽度（267次比较中的64次）远窄于音高平台（267次中的210次）。由于连续滑动窗口比较的理论最大值由窗口几何决定（最大进出转移时为1/√(L-1)），L=6时的音高值及其宽平台本身并非强证据。两个维度的对齐与边界敏感性一致，但宽平台排除了将任一曲线单独作为唯一自动分割器的可能。500次重合成实验量化了与源数据的偏离，并暴露了L=2时的精确复制简并现象。

RecurSE: Bounded Recursive Self-Evaluation for LLM Rubric Judges（RecurSE：面向LLM评分裁判的有界递归自我评估）

本研究提出RecurSE框架，旨在消除LLM-as-judge（大语言模型作为裁判）在强化学习训练中对昂贵外部监督的依赖，实现模型利用自身评估能力生成学习信号的闭环递归自我提升。

核心创新：采用双通道结构——可训练的裁判（Pass 1）按规则评估候选回答，同步的策略副本检查器（Pass 2）依据元规则审查裁判推理并提供标量过程奖励。通过接口解耦，从结构上隔离检查器的标量分数与裁判的判定令牌，消除了导致自我奖励膨胀的退化解码捷径。

关键机制：提出成对优势有效性（PAV）作为无偏验证监控器，联合追踪裁判精度与检查器保真度，可靠识别最优早停窗口，以应对无锚递归学习固有的有界性。

实验验证：在Qwen3.5-9B、Gemma-4-E4B-it和Qwen3.6-27B上，RecurSE在医学、成对比较、摘要及专业基准上均取得一致的泛化提升。消融实验表明，同步裁判-检查器协同进化优于冻结检查器、外部元裁判、自一致性及强教师蒸馏。

结论：当自我产生的奖励有效性被显式解耦并持续监控时，有界递归自我提升对LLM裁判是可行的。此外，该框架生成的偏好对可有效增强下游策略对齐。

ACE: A Self-Correcting Agentic Canvas Editor for Multi-Slide Presentation Automation（ACE：用于多幻灯片演示自动化的自校正智能画布编辑器）

核心问题：商业设计平台通过LLM智能体编辑文档时面临两大实际障碍：一是传统文档格式仅暴露扁平化绝对定位元素，智能体需反复计算坐标并易破坏布局；二是设计任务缺乏唯一标准答案，基于参考差异的评估指标会误罚合理但不同的输出。

关键结果：固定骨干模型下，单轮场景图编辑器已可匹敌同骨干内部迭代的HTML智能体流程；添加自校正后，ACE在94任务基准上IF显著提升（4.23 vs 3.81，配对p=.010，外循环评委复现），速度提高1.75倍，成本降低约44%。VQ均值无统计差异，但26名盲测评分者整体偏好ACE（58.7%决定性胜率），81%情况下偏好自校正输出；排名在三种评委家族中不变，外循环评委保留三分之二自校正增益（排除循环性偏差）。66%案例一轮即停，严格峰值回滚消除了所有观察到的性能回退。

Image Difference Quantification Using Autoencoder-Based Latent Representations（基于自编码器潜在表示的图像差异量化）

传统图像相似度指标（如MSE、PSNR、SSIM）依赖像素级比较，常无法捕捉感知上有意义的图像差异。相比之下，深度神经网络学习的潜在表示编码了与人类视觉感知更一致的高层语义信息。本文提出一种基于卷积自编码器的框架，在潜在空间中使用余弦相似度量化图像差异。学习到的紧凑嵌入能够在光照、姿态和背景变化下稳健区分视觉上不同的图像。在猫狗图像及跨域数据集上的广泛评估表明，潜在空间中存在清晰的类内聚类和强类间分离性，98.4%的猫狗图像对的相似度得分低于0.5。使用TID2013数据集的进一步验证显示，潜在空间距离与人类平均意见得分（MOS）呈正相关，表明对感知相关图像失真的敏感性。该方法为传统基于像素的相似度指标提供了一种计算高效且具有语义基础的替代方案，可应用于基于内容的检索、感知质量评估和语义相似性分析。

BrowserForge: Scaling Web Episode via Parallel Browser Sandboxes（BrowserForge：通过并行浏览器沙盒扩展Web智能体训练数据）

核心问题：基于渲染像素的Web智能体能规避解析HTML或无障碍树带来的脆弱性和高token成本，但其训练依赖海量高质量交互轨迹，而如何大规模生成此类数据仍是未解难题。现有公开数据集通常仅含数千条轨迹，且局限于固定的窄范围网站；即便最新的自动合成流程也受限于预定义网站列表或教程来源，导致智能体见过的不同网站数量几乎不增长。

方法：提出BrowserForge框架，通过在开放互联网上并行驱动多个浏览器沙盒，大规模生成Web交互数据。框架耦合三大组件：开放网络数据采集阶段（让智能体接触数十万个真实可访问网站）、沙盒集群管理器（调度数百个高利用率并发浏览器）、Proposer-Solver双智能体循环（将原始页面转化为可执行任务并收集验证轨迹）。规则+模型联合清洗流程剔除失败运行，并将留存推理统一改写为单一思维链风格。页面结构（如无障碍树）仅作为合成阶段的辅助信号，训练和发布的智能体纯靠截图决策。

成果：生成的语料包含203,238条轨迹，每条来自不同网站，规模和多样性均超越此前轨迹数据集。在该语料上微调紧凑多模态模型，其在实况Online-Mind2Web上的成功率从25.66%提升至33.33%，在静态Multimodal-Mind2Web上的步骤准确率也持续改进，且增益随语料规模扩大而增长。控制实验进一步证实，开放网络数据采集和广泛的网站覆盖是性能提升的关键因素。

SkillForge: Evolving Verifiable Skills for Reinforcement Learning Agents（SkillForge：为强化学习智能体进化可验证的技能）

核心问题：现有基于LLM的强化学习智能体大多为“片段式”学习，无法跨片段积累可复用知识。SkillRL等技能学习方法虽能从轨迹中提取技能，但将技能库视为只增不改的仓库，未验证已存技能是否依然有效，导致技能质量下降。

方法创新：本文提出SkillForge框架，支持技能的持续进化——通过环境交互对技能进行验证与精炼。关键设计包括：(1) 在智能体交互中显式化技能使用，使强化学习可直接优化环境动作与技能调用决策；(2) 引入基于证据的技能验证机制；(3) 设计多路径技能归纳方法，使技能库在持续增长的同时保持质量。

实验结果：在ALFWorld、WebShop和AppWorld三个基准上的大量实验表明，SkillForge持续优于SkillRL，验证了“持续验证技能”对训练更强LLM智能体的有效性。

RePolicy: Reinforcement Learning for Safety-Policy Invocation in Agent Safeguards（RePolicy：面向智能体安全防护中安全策略调用的强化学习方法）

核心摘要：保障语言模型智能体的安全需要根据上下文相关的安全策略评估完整的执行轨迹。现有策略感知型防护手段主要依赖提示工程或监督微调，难以适应未见轨迹与动态变化的策略情境。本文提出RePolicy——一种通过强化学习学习安全策略调用的智能体防护机制：给定智能体轨迹与动态策略库，RePolicy调用适用策略，并基于策略内容生成有依据的推理与安全判定。研究构建PolicyTraj-20K数据集用于监督初始化，随后采用带有可验证奖励与策略上下文扰动的GRPO方法训练。在六个智能体安全基准上的实验表明，RePolicy实现了强大的整体安全检测性能，并在不同策略情境下具有稳健的策略调用能力。

Beyond Static Interpretability: Anticipating Post-SFT Mechanisms from Pre-SFT Parameters for Better Tuning（超越静态可解释性：从预SFT参数预判后SFT机制以实现更优微调）

核心观点总结：

1. 问题提出：机械可解释性与后训练优化的结合（“定位-微调”范式）受限于可解释性的追溯性——对预SFT模型直接解释会产生误导，特别是在新任务上，初始识别出的神经元与最终控制模型的神经元差异巨大，引入偏差，反而干扰监督微调（SFT）。

2. 解决方案：提出一种前瞻性定位框架，仅利用预SFT参数与目标数据集，即可准确估计后SFT的可解释性状态，从而避免追溯性偏差。

3. 理论创新：将SFT建模为连续参数演化过程，利用泰勒展开严格桥接微调后的机械目标与预SFT模型的动态梯度，为前瞻性定位提供数学基础。

4. 实践设计：构建双粒度（神经元级与组件级）定位流程，兼顾细粒度与结构性识别。

5. 实验验证：广泛实验表明，所提方法不仅提供更优的SFT指导，且在不同模型规模上展现出稳健性能与时间可扩展性。

6. 意义突破：该工作超越了传统可解释性的根本局限——无法在任务关键机制训练之前识别它们——开创了将机械可解释性与目标优化结合的前瞻性研究前沿。

不确定性量化（UQ）对于提升深度学习模型预测的可靠性至关重要，尤其是在高维输出空间场景下。本文聚焦高维回归任务中偶然不确定性（捕获数据固有噪声）与认知不确定性（量化模型对陌生条件的置信度）的联合建模，指出仅建模其中一种会限制透明度和鲁棒性，而联合建模能同时反映不可避免的变异与知识缺口，从而实现更可靠的预测。作者提出一种新方法，采用低秩加对角协方差结构近似联合不确定性，在捕捉关键输出相关性的同时避免全协方差矩阵的计算负担。与以往工作不同，该方法将偶然与认知不确定性显式整合为统一的二阶分布，支持采样和对数似然评估等稳健的下游分析。此外，文中引入了训练与推理的稳定化策略，在图像修复、着色、光流和深度估计任务中取得了优越的UQ性能。

Preference Data Selection for Mitigating the Alignment Tax in Large Language Models（偏好数据选择以减轻大语言模型中的对齐税）

核心观点总结：本文针对大语言模型对齐过程中常见的“对齐税”问题（即灾难性遗忘预训练通用能力）提出了一种名为BALIGN的平衡数据选择策略。与以往从优化或架构角度切入的研究不同，本文聚焦于偏好数据本身的内在特征，通过理论和实证分析偏好优化梯度，识别出驱动参数漂移的三种关键数据特征——参考模型的对数概率边际、被选与拒绝回复之间的token长度差异、以及与通用能力语料的TF-IDF相似度。BALIGN将这些正交特征聚合为一个统一的综合风险评分，系统性地过滤掉会扰乱模型内在参数或对齐效用极低的高风险偏好样本。在标准人类偏好数据集上的大量实验表明，BALIGN在保持对齐收益的同时显著保留了基础能力，以极低的计算开销持续达到最优帕累托前沿。
