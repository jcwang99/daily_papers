When Does Machine Learning Beat Value Sorting? A Three-Dataset Diagnostic of Exposure-Weighted Shipment Prioritization（机器学习何时能击败价值排序？跨三个数据集的暴露加权货运优先级诊断）

延迟风险模型通常以预测准确性来评判，但实际更关注的是：在只能审查少量货运的情况下，管理者应优先检查哪些？本文评估机器学习是否超越了“优先检查最高价值货物”这一高要求的无模型基准线。基于SCMS采购、DataCo物流和Olist电商三个真实供应链场景，采用泄漏控制滚动原点评估和1000次配对自助法置信区间。按预测延迟严重程度乘以已知价值排序（M1）在三数据集中均优于仅按严重程度排序，但总体并不优于价值排序。在10%审查预算下，M1相较于VALUE_ONLY的差异：SCMS为-5.5个百分点，DataCo为+10.1个百分点，Olist为-4.9个百分点。这一差异与严重程度可学习性一致：DataCo的R²为0.27，校准偏差+0.01天；而SCMS和Olist的R²约为-0.02，校准偏差为负。嵌套交叉验证的成本敏感重训练并未比M1带来稳定改进。本文不提出新学习算法，而是提供一种部署诊断与评估协议。价值排序应作为永久基准，仅当严重程度可学习性与校准性通过审计，且模型在泄漏控制滚动原点评估中通过该门槛后，才应部署机器学习。

5G蜂窝网络上的联邦学习（FL）虽能保护原始数据，但仍易受到侧信道泄露的攻击。与以往假设具备数据包级网络可见性的指纹攻击不同，在5G物理层中，用户有效载荷被加密，且无线网络临时标识符（RNTI）可能随时间变化。然而，研究发现，通过物理下行控制信道（PDCCH）广播的物理层调度元数据保留了与架构相关的时间模式。为此，本文提出FLINT——一种新颖的黑盒指纹识别框架，仅利用粗粒度的物理层观测数据即可推断出FL模型架构类型（包括CNN、RNN和Transformer）。FLINT通过解码PDCCH调度信息、将变化的RNTI映射到物理用户设备，并应用多视图时间建模来区分特定架构的训练行为，从而克服了网络层不可见的问题。这种泄露具有严重的安全风险，因为获知客户端模型架构可将被动侦察转化为有针对性的下游利用。在基于srsRAN的5G空中测试平台上进行的大量实验表明，FLINT对架构族分类的宏F1分数达到0.930。据我们所知，FLINT是首个利用任何协议感知的对手均可获取的低层5G侧信道信息来识别AI/ML模型架构的工作。

文本行人检索面临一个关键但尚未充分探索的挑战：实际场景中查询粒度的固有不确定性。本文提出了一种新范式——任意粒度文本行人检索，并提供了系统性解决方案。首先，形式化定义了五级粒度谱，并通过新颖的多粒度文本标注引擎构建了高质量的多粒度数据集UFine6926-MG。其次，提出综合评估基准MG-Eval，包含逐步细化的文本和反映真实语义的跨身份标签。第三，在全面诊断揭示现有研究系统性局限后，提出跨模态多粒度对齐与匹配框架CMAM，通过正交专家感知解耦粒度特征、概率对齐建模查询不确定性下的多对多匹配以及粒度一致性推理实现粒度感知检索。实验表明，CMAM在所有粒度级别上都显著优于现有最优方法。本研究为构建更实用的行人检索系统奠定了基准和稳健基线。

Exposure is Optional: Learning Unlike Coordination in Language Models（暴露并非必需：语言模型中的非同类并列学习）

协调（并列）是基本语言结构，但对其本质仍存在争议。传统观点认为只有同类成分才能并列，但自然语言中存在大量语法正确的非同类并列现象。本文以语言模型为计算实验平台，探究学习非同类并列是否需要训练数据中的直接暴露，还是可以从一般性的组合能力中自发产生。通过使用过滤语料训练（FiCT），我们从训练语料中移除所有非同类并列实例来训练GPT-2模型。结果发现直接暴露并非必需：在过滤数据上训练的模型能成功泛化到非同类并列，其困惑度和语法判断与未过滤文本训练的模型相当。此外，内部表征分析表明，语言模型通过将并列元素视为相似结构类别，或通过类似删除的机制来处理非同类并列，这两种机制都可以仅从同类并列暴露中学习。本工作加深了对语言模型内部表征语言结构的理解，同时通过展示模型无需直接暴露即可泛化处理非同类并列，为更广泛的并列结构争论提供了新见解。

针对冻结感知模型在端到端自动驾驶中存在的任务线索衰减与静态融合问题，本文提出名为PerceptDrive的先验到规划迁移框架。该框架将来自冻结驱动适配提供者的教师蒸馏先验与来自冻结自监督视频编码器的稠密观测潜变量，输入可训练的专家路由世界-动作模型。专家特定查询分支处理信号，并通过先验保留目标将各分支锚定至对应先验。路由器从共享场景表征预测软门控，并在轨迹生成前组合专家条件。训练中，基于规则的子度量估计为分支轨迹草稿提供软门控蒸馏目标；预测的无动作未来潜变量则条件化流匹配执行器。推理时无需特权组件、评分或搜索，仅凭单个前视相机即可生成规划轨迹。在NAVSIM v1上达到90.4 PDMS、v2上达到90.2 EPDMS，消融实验证实先验保留与场景条件路由的互补增益及三种先验的差异化依赖，证明保留并自适应路由感知先验可直接提升规划性能。

RIM: A Retrieval-In-Matching Framework for Cross-Domain Global Visual Localization of UAVs（RIM：面向无人机跨域全局视觉定位的检索-匹配融合框架）

本文针对无人机（UAV）基于遥感参考地图的全局视觉定位中，因采集时间和成像平台差异导致的跨域外观和视角变化问题，提出RIM框架。核心方法包括：从Google 3D Tiles按采样点、高度和方向生成无人机视角参考视图；采用两阶段跨域微调策略，利用正样本和地理远距离难负样本优化SALAD模型，并结合局部几何一致性对Top-K候选进行重排序。RIM通过冻结DINOv2-B检索器并蒸馏局部描述符解码器，重用其标记场与浅层VGG19细节流，实现一次查询前向传播同时完成检索与局部描述，无需额外基础模型骨干。在重建的EPFL Urbanscape及自采的Chang'an Park数据集（均与训练数据地理无交集）上进行零样本评估，RIM在25/50米全3D距离指标下，Recall@1相比SALAD分别提升8.55/13.77百分点（EPFL）和4.45/8.94百分点（Park）。在Top-K=5时，完整定位查询（含检索、候选匹配及鲁棒几何验证）端到端耗时67.9毫秒，比最强的独立稀疏匹配基线快1.8倍，比RoMa快40倍以上，同时达到可比的重排序精度。该工作为GNSS受限环境下的无人机全局视觉定位提供了高效可部署方案。

Agentic Context Management: Solving Agent Memory and Cost by Treating Them as Lifecycle and Architecture Problems（代理上下文管理：通过将记忆与成本视为生命周期与架构问题来解决它们）

生产环境AI代理的失败往往不是因为推理能力不足，而是因为无法管理其推理上下文中的内容（如对话历史、大型提示、工具定义及膨胀的工具输出）。代理会因自身不断积累的历史而“淹没”，同时每轮交互产生的令牌成本不断上升，导致跨对话及对话内部出现记忆缺失。目前的应对方式将此视为存储与检索问题，但我们认为这一框架过于狭隘。主动管理代理所“记住”的内容是一个生命周期问题，而非单纯的存储问题：它涉及决定记住什么、提取并结构化信息、根据数据类型选择适当的存储方式、在保留来源信息的前提下进行整合与遗忘、判断当前相关内容、预测下一步需求，以及在不丢失重要信息的前提下将上下文压缩至预算范围内。在严肃的生产环境中，这并非针对单一用户，而是跨越组织层级范围。我们将此学科命名为“代理上下文管理”（ACM），并将其分解为五个基本原语：架构设计、摄入、范围界定、预测，以及压缩与整合。在此基础上，我们从经济学角度论证：朴素的上下文积累会导致令牌成本随对话长度呈二次方增长；粗糙的摘要虽能实现线性成本，但会引发准确性断崖式下降；只有经过验证的压缩才能在保持保真度的同时实现线性成本。我们描述了一个参考实现Maximem Synap，该实现将五个原语作为多租户服务部署，在第六节详述的配置下，在LongMemEval上达到92%，在LoCoMo上达到93.2%。最后，我们指出现有基准尚未涵盖的维度：延迟、令牌效率、上下文抵抗性，以及该类别所指向的决策级别与组织级别上下文的前沿方向。

OpenRTAG: A Comprehensive Benchmark for Robust Text-Attributed Graph Learning under Data Quality Degradation（OpenRTAG：数据质量退化下鲁棒文本属性图学习的综合基准）

文本属性图（TAG）结合了关系结构与丰富的节点文本，但现实中的TAG常存在文本、结构和标签的质量问题，表现为稀疏、噪声和不平衡。这定义了九种典型的退化场景，严重影响TAG学习。现有研究虽有特定缓解策略，但证据分散在不同退化类型、数据集、任务和模型家族中，导致对TAG鲁棒性理解不足。为此，我们提出OpenRTAG，一个统一的3×3分类法，支持跨九个TAG数据集和三个下游任务的标准化评估。它系统评估场景有效性与模型敏感性，比较传统GNN、LLM-GNN和代表性图基础模型，考察场景匹配基线的效果、效率和鲁棒性，并进一步分析复合退化场景下的模型行为。OpenRTAG为理解低质量真实环境下TAG学习的鲁棒性提供了标准化测试平台。

多模态视频虚假信息检测通常被视作一个整体视频理解任务，需一次性处理并判断整个视频及其关联内容。然而，现实中的虚假信息往往呈现稀疏且组合的证据结构：可靠的判断可能仅依赖于少数几个耦合线索，而大部分视频内容提供的额外信息有限。因此，穷尽式的多模态推理可能引入大量冗余，并掩盖决定性证据。这促使将证据获取与验证解耦：先识别稀疏、与决策相关的线索，再基于所获证据判断真实性。据此，我们提出SIEVE框架，即面向多模态视频虚假信息检测的稀疏交互式证据验证框架。一个证据搜寻智能体主动探索可用的多模态证据，并构建一个紧凑的证据包，随后由验证器利用该证据包判断真实性。该智能体通过监督式证据搜寻轨迹以及一种证据感知的强化学习目标进行训练，后者在鼓励获取信息性证据的同时，抑制不必要的或无效的交互。在多个视频虚假信息基准测试上的实验表明，SIEVE持续优于所评估的基线模型，并能利用紧凑的证据包实现可靠的验证。此外，其证据获取过程提供了显式、可检查的证据轨迹，提升了多模态虚假信息检测的透明度和可归因性。

Toward Optimal Adenovirus Detection Using YOLO26（基于YOLO26的腺病毒最优检测方法）

本研究系统性地评估了YOLO26不同模型规模下的多种数据增强配置，以确定在透射电子显微镜（TEM）图像中检测腺病毒的最有效方法。所评估的配置包括NAS、GAS、GMAS和DAS，均在相同的训练条件下进行测试。腺病毒数据集选自已发布的TEM病毒数据集，通过利用腺病毒颗粒位置重新标注，生成兼容YOLO的边界框注释。实验结果显示了不同数据增强配置对YOLO26检测腺病毒的影响，并指出了最有效的增强方案。

QuantiBias: Benchmarking Quantization-Induced Bias in LLMs（量化偏差基准：评估大语言模型量化引入的偏见）

几乎所有面向广泛受众的大语言模型都会经历量化：以全精度训练，再压缩以提高效率。这一步骤通常被认为无害，其安全性鲜少被重新检验。我们发现，其主要副作用是增加了标准安全评估无法检测出的偏见。在保持模型、训练和提示词不变的情况下，量化后的模型依然能拒绝有害请求、避免过度拒绝良性提示，并选择无偏见的多选题答案。然而，面对开放式问题时，同一模型在我们探测的所有八种语言中，均会自发输出刻板印象；在独立裁判评估下，约四分之一的开放式回答（在压缩梯度的各个阶段约为24%至27%）存在偏见——它通过了所有标准检查，却仍以显著更高的偏见水平到达用户手中。这种选择性差距是一个稳健的发现；而开放式偏见是否会随压缩进一步增加则较不确定，且依赖于评分裁判的判断。为此，我们提出QuantiBias基准测试：它结合了生成式多语言刻板印象探测与拒答及多选题控制项，以隔离开放式生成；对比了有无推理的不同模型构建；并对其生成内容的严重性进行评级。基于两个基础模型（Qwen和Gemma）、五类量化方案及八个基准测试，我们发现量化器会根据不携带偏见抑制信号的能力数据来分配额外精度，而回答前的推理在某些方案中可将效果减半，但在其他方案上完全无效。因此，量化后的模型必须针对开放式偏见重新评估，而不仅仅依赖其已通过的那些简短形式的安全检查。
