Probing Association Instability with Track-State Perturbations for Clip-Level Active Learning in Query-Propagation Multi-Object Tracking（利用轨迹状态扰动探测关联不稳定性用于查询传播多目标跟踪的片段级主动学习）

核心问题：训练查询传播的端到端多目标跟踪（MOT）模型需要大量视频序列的密集边界框和身份标注，导致数据集构建成本高昂。片段级主动学习通过选择视频片段进行标注来降低成本，但现有基于输出级时间不确定性的采集标准可能遗漏那些信息量源于传播轨迹状态中关联不稳定的片段。

提出方法：提出QPID（查询传播不稳定性和多样性），一种针对查询传播MOT的片段采集方法，专门瞄准传播轨迹状态中的关联不稳定性。QPID通过对内部轨迹状态施加双向扰动，并测量与干净参考分支的预测差异来估计这种不稳定性。其关键思想是：在稳定片段中，每个传播轨迹在小扰动下应持续跟随同一目标；而在模糊片段中，轨迹状态的微小变化可能改变轨迹跟随的目标，导致定位或置信度变化。

评估指标：QPID用两个指标衡量扰动导致的预测差异：定位漂移和熵加权置信度差异。这些指标被聚合为片段级关联不稳定性分数。为避免仅选择不确定性的冗余，QPID利用不确定性加权视觉覆盖和轨迹级视觉原型，从高不稳定性片段中选择代表性标注批次。

实验结果：在DanceTrack和SportsMOT上使用MeMOTR和SambaMOTR的实验表明，在相同标注预算下，QPID相较于主动学习基线取得了强劲性能。

No Gaussian Required: Contrastive Inverse Dynamics for JEPA World Models（无需高斯假设：面向JEPA世界模型的对比逆动力学）

联合嵌入预测架构（JEPAs）通过学习预测未来嵌入来构建世界模型，但其目标函数存在常数编码器的平凡解，因此所有实际系统均需加入防坍缩机制。LeWorldModel（LeWM）利用SIGReg正则化器防止表征坍缩，强制隐分布匹配各向同性高斯分布——即通过预设表征形态来稳定模型，但这种方式与环境本身无关。本文提出，防坍缩压力完全可以来自转移数据本身。Action-Contrastive Masked Transition Modeling（AC-MTM）保留LeWM的前向隐预测目标，额外增加一个仅用于训练的逆动力学分支，采用Action-NCE损失训练：每个隐转移必须在批次中区分出产生该转移的动作，而坍缩编码器必然无法完成此判别任务。逆分支在训练后被丢弃，推理时编码、前向预测、规划及计算量与LeWM完全一致。在四个标准像素控制任务（匹配规划协议）下，AC-MTM可从零稳定训练，平均性能与SIGReg持平。在更具挑战性的多物体OGBench视觉场景任务中，结果一致表明预设几何成为瓶颈：AC-MTM达到80.0±2.0%成功率，而SIGReg为58.0±2.0%，每个训练种子均提升20-24个百分点。单次50回合随机策略运行给出52%基线估计。对比逆动力学因此提供了一种无分布的防坍缩信号，无需目标网络、停止梯度、预训练编码器或重建目标，本文并刻画了其成立所需的动作空间与可观测性假设。代码已开源：https://github.com/jackboyla/action-contrastive-jepa

SignalReasoner: Assessing the Upper Bound of 3B Models for Signal Mathematical Reasoning（SignalReasoner：评估3B模型在信号数学推理中的上限）

核心摘要：本文探讨了通过强化微调策略，将Qwen2.5-3B-Base模型适配到研究生级别的信号处理数学问题（基于WirelessMATHBench-XL基准）中的方法。研究对比了两种训练范式：（1）在WirelessMATHBench-XL上直接进行基于可验证奖励的强化学习（RL）；（2）先在蒸馏的无线领域思维链（CoT）语料上进行监督微调（SFT），再进行同领域的强化学习。同时，文章对GRPO、GSPO和GMPO三种策略优化算法进行了基准测试，旨在评估领域感知的CoT监督微调是否为后续强化学习提供了有效初始化，以及GSPO/GMPO相比GRPO在信号推理任务中是否具有稳定性或准确性优势。主要结果：最佳模型总体准确率达到39.12%，相比未训练的基座模型（12.37%）提升了三倍以上。

TINA+: Probing Residual Visual Knowledge in Unlearned Diffusion Models via Diffusion-Consistent Text-Free Inversion（TINA+：通过扩散一致的无文本反演探测未学习扩散模型中的残余视觉知识）

尽管文本到图像的扩散模型展现出强大的生成能力，概念擦除技术对于防止有害内容生成至关重要。现有的对抗性探测方法通过测试被擦除的概念是否仍可被恢复来评估这些技术，但它们在本质上仍以文本为中心——关注文本到图像的映射是否被切断，而忽视了相应的视觉知识是否仍然存在。为从视觉角度探究该问题，本文利用扩散反演来探测生成轨迹能否重构被擦除概念的视觉实例。在空文本条件下，标准反演虽绕开了文本通路，却放大了近似误差，阻碍了轨迹的忠实恢复。为此，本文提出TINA+，一种配备基于优化的反演的扩散一致无文本反演攻击方法。此外，本文发现无约束的扩散反演可能发现虚假轨迹，甚至允许随机初始化的扩散模型重构目标概念，从而错误地指示残余视觉知识的存在。为抑制这一失败模式，TINA+引入扩散一致轨迹正则化，通过惩罚远低于扩散预期边际能量演化的轨迹，抑制虚假反演路径，同时保留恢复被擦除概念的能力。在十二种擦除方法、四个概念擦除任务及不同模型架构上的实验表明，TINA+能够通过扩散一致的视觉轨迹可靠地探测残余视觉知识。这些结果提供了更强证据，表明当前方法往往通过切断文本—图像关联来掩盖概念，而非真正消除底层视觉知识。

Judge, Retrieve, or Abstain: Uncertainty-Guarded LLM Judging with Provable Risk Guarantees（判断、检索或弃权：具有可证明风险保证的不确定性守卫式大语言模型评判）

核心观点总结：

1. 问题背景：使用LLM作为评判者已成为大规模评估模型输出的标准做法，尤其适用于无单一参考答案的主观开放任务（如有用性或对齐性评估）。然而，客观任务对无参考的LLM评判提出了独特挑战——评判者需通过参数化知识或工具增强来判定事实正确性，前者可能产生幻觉或证据不足，后者虽可补充证据但增加计算成本且需确定可靠使用证据的机制。

2. 核心缺陷：单独使用任何一种方法都无法对已接受裁决的风险提供正式控制，也无法在指定水平上保证其可靠性。

3. 提出方法：提出一个风险控制框架，在保留集上校准不确定性阈值，利用有限样本Clopper-Pearson区间，使已接受裁决中的错误发现率以高概率保持在用户指定水平α以下。

4. 双阈值路由机制：当参数化模式不够自信时，实例被路由至检索增强模式，评判者收集网络证据并在第二个校准阈值下重新评估；有限样本保证无需额外假设即可延续至该双阈值路由。

5. 实验结果：在开放域问答基准和不同规模的评判模型上，该框架在维持目标错误率的同时，实现了比单模式基线显著更高的覆盖率。

Language Has Two Parameters: Narrative-Induced Semantic Plasticity and Phase-Sensitive Interpretation（语言具有两个参数：叙事引发的语义可塑性与相位敏感解读）

本文提出语言具有两个参数。第一个参数是“幅度”，即通过统计词语共现频率来估计的关联强度；词嵌入和注意力权重是对这一统计的精细化，但其汇总了语料库中所有作者的写作模式。本文主张存在第二个参数——“相位”，这是仅靠从语料库中学习的有符号权重无法提供的。相位只存在于意义之间：它决定共同激活的意义如何组合，且能在意义完全在场的情况下逆转该意义的贡献。说话者可通过语言形式在信号中设置相位；遭遇事件（encounters）建立相位关系，历史分布这些关系。总体平均会抹除历史索引的相位：去除主体索引的语料库只能识别总体边际状态，无法确定任何个体或二元组状态（无论尺度大小）。标准Transformer在冻结推理中对相位没有显式表征，而以单义性（monosemanticity）衡量进展的可解释性研究恰恰在与其对抗：它视为缺陷的共存状态，恰恰是典故、反讽和引用的条件。本文提出六项预测，检验被抑制的意义是否仍保持活跃、遭遇顺序是否改变短语的功能、标记信号是否改变共享短语的理解方式，以及模型是否会被赋予它的历史所改变（而不仅仅是被告知）。论文捍卫的是弱版本论点：解释需要第二个关系参数，该参数有符号、持久，且索引到个体和二元组。量子概率只是该参数的一种记法，形式体系中没有任何内容声称大脑中存在量子过程。强版本论点（即量子演算以有符号经典模型所不能的方式约束这些现象）则依赖于尚未推导出的遭遇顺序约束。该理论所要求的架构是一种具有主体索引、承载相位的语义状态的语言模型。

（1）阐明了策略组合验证与合成的计算复杂度：验证一个给定组合在确定性组合与无环RMDP中即已属于$\forall\mathbb{R}$-完全问题；合成有界规模组合在一般有理多面体（即便固定折扣与无环动态）属于$\exists\forall\mathbb{R}$-完全问题；单一策略情形兼具组合与代数层面的困难。
（2）提出了一种可离线构建、便于运行时个性化的策略组合方法，兼顾实际部署的可行性。

D²ACCI: A Dual-Loop Diagnostic Protocol for Evidence-Preserving Agent Memory（D²ACCI：一种保留证据的智能体记忆双重循环诊断协议）

结论：稳健的记忆系统迭代要求可追踪、有统计依据且考虑回归的证据——这正是D²ACCI填补的空白。

BrainNorm: A Foundation Model that knows Normal via Semantic Atlas Pretraining（BrainNorm：通过语义图谱预训练识别正常状态的基础模型）

本文提出了BrainNorm，一个规范性基础模型，在约66,000例T1加权结构MRI扫描上完成训练与测试。该模型利用语言-图像风格对比预训练方法，在跨年龄的健康人群队列中学习了一个语义图谱潜在空间（SAL），其中每次扫描被表示为一组图谱分区嵌入。这产生了分区特异性的健康衰老模板轨迹，支持与受试者实足年龄一致的模板匹配和局部偏差评分。在6个下游队列中，BrainNorm在25种任务-设置组合下验证了泛化能力，涵盖年龄估计、脑龄差距估计、分区识别及单病种与多病种分类任务，并在直接推理、零样本、少样本和全数据线性探测等设置下进行评估。SAL空间中产生的偏差模式使得利用分区级异常进行疾病预测的零样本任务成为可能。仅在下游数据集健康队列上进行微调可进一步提升多种任务的性能。在所有分类任务中，对BrainNorm冻结嵌入的线性探测优于9种在端到端监督下微调的基线方法。此外，BrainNorm在各种神经退行性疾病中识别出的局部偏差与临床文献中已确立的神经退行性病理高度一致。

DistillPath: An Efficient 22M Distilled Pathology Encoder Approaching Large Foundation Model Performance（DistillPath：一种接近大型基础模型性能的高效2200万参数蒸馏病理编码器）

核心摘要总结：

1. 问题背景：当前高性能病理切片编码器多为数亿至超十亿参数的基础模型，在普通硬件上编码和存储全切片图像中的数千个切片成本高昂，因此紧凑型编码器是具价值的替代方案。

2. 方法创新：提出DistillPath-KS16，从现有2200万参数的kaiko ViT-S/16编码器出发，通过蒸馏已发布的病理编码器（作为冻结教师模型）进行改进。该方法仅读取教师的最终类别和块标记，在6000张公共切片上训练，无需DINO或iBOT预训练头，也无需数十亿切片语料库，适用于任何暴露主干标记的已发布编码器。

3. 实验结果：将四个参数范围从8600万到11亿的教师模型蒸馏到同一学生模型中，每个变体在EVA、HEST和PLISM三个基准上均优于kaiko基线，最强教师模型取决于任务。在七任务EVA均值上，DistillPath-KS16-Virchow2达到0.795，仅比评估中得分最高的Virchow2低0.015分，但参数减少约29倍；该模型在此综合指标上也优于H0-mini和GPFM，尽管优势集中在特定任务而非均匀分布。

4. 效率优势：由于保持2200万参数和384维特征的ViT-S/16架构，DistillPath-KS16的运行速度比Virchow2快25倍以上。

5. 资源可用性：代码和模型权重已公开发布（代码：https://github.com/RamonKaspar/DistillPath，权重：https://huggingface.co/collections/RamonK/distillpath）。

An Omitted Mode Is a Rare Rule: The Sampling-Verification Danger Law in Continuous Code World Models（遗漏模态是罕见规则：连续代码世界模型中的采样-验证危险定律）

核心问题：在代码世界模型（Code World Model）范式中，LLM生成可执行的世界模型供经典规划器搜索，模型仅在复现采样转换时被接受。本文追问这种接受在连续控制中究竟证明了什么。

主要发现：

1. 危险精确分解：将流程危险定义为期望风险，精确因子为：N次独立门控rollout全部错过概率为r的关键事件的概率恰为(1-r)^N；独立接受样本将其预算加入指数。

2. 实证漏洞：在三种混合仪器上，被接受的忽视模态模型可被利用——规划器被固定在模态边界，遗憾值接近全部可获得回报。

3. 局部化预算（边界点有效）：Lipschitz常数至多为L的模型，在一点相差η时，在体积至少κ((η-ε)/L)^(d+m)的区域上分歧超过容差ε；所研究的非连续重置模态无需支付此预算。

4. 真实LLM合成实验结果：GPT-5.x在111次含模态采样中105次修复遗漏的1D夹紧（clamp）；50/56仪器流块上每次尝试精确（95% CI [0.781, 0.960]）。但在2D区域上无任何产物恢复规则（0/156）；八次定向干预均未消除失败，阳性对照定位了问题：已定位的规则未被诱导，而给定形式和位置后常数精确遵循。

5. 版本空间证书：证明可辨识性是类相对的——在最宽剂量下，声明拟合在20/20块中成功，且每个采样一致圆在18/20块内处于容差内。证明一类条目规则与每个采样完全一致但在实际运行中无害，因此可辨识性是仪器的可测量属性。

6. 结论：对全部1034个产物在独立样本上重新评分，确认接受仅证明采样一致性，无更多含义：在门控可证明有信息量的地方，它仅覆盖被利用规划器查询的约2%。

Preference Is Not Intervention: The Structure and Stability Boundaries of Reader-Specific Evidence Utility（偏好不等于干预：读者特定证据效用的结构与稳定性边界）

核心问题：机器学习系统越来越多地根据下游模型身份做决策，但只有当模型间差异形成可复用结构而非输入局部交互时，这种条件化才有用。本文在检索增强生成（RAG）中对此进行测试，其中证据效用可在受控干预下测量。

主要发现：在固定查询、证据、任务、评分和干预的条件下，9个读者在33%的共同影响单元上对效应符号存在分歧；读者×查询交互解释了29.8%的效用方差（置换零假设为8.4%）；自选证据使F1提升+0.031（t=3.39）。

更精确的追问：异质性中哪些成分是跨查询稳定的读者属性？将三个可测量对象分离——证据活动性、序数偏好、条件符号方向——发现序数读者几何在四个独立设置中稳定（分裂半ρ=0.60–0.83）：留一干预、PRISM偏好、RAMDocs和RAGuard。

符号几何的边界：符号几何受任务约束——在开放式问答中较弱（0.14, 0.35），尤其对误导性和无关证据效果差；但在二分类事实核查中较强（0.75），无显著序数差距，但仍低于其稀疏匹配上限。稀疏性、解码噪声和度量伪影不能解释主要的序数-符号差距。

关键结论：稳定的序数相似性无法预测跨读者干预迁移（预言距离ρ=-0.27；后悔可靠性-0.28）。读者特定效用存在，但偏好不等于干预：稳定的排序相似性并不授权帮助/伤害决策的迁移。
