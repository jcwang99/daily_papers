S-CEReBrO: Breaking the Memory Barrier in Continuous EEG Monitoring（S-CEReBrO：打破连续脑电监测中的记忆瓶颈）

核心问题：基础模型在脑电图（EEG）分析中具有巨大潜力，但基于Transformer的架构存在关键瓶颈——全局注意力机制将注意力记忆状态与信号时长耦合，导致连续监测时发生内存溢出。

创新方法：提出S-CEReBrO（流式CEReBrO），引入新型窗口交替注意力机制，将注意力计算分解为固定大小的时空窗口，保证KV缓存内存恒定（仅活动窗口需驻留注意力图）。

性能优势：经验缩放分析表明，窗口交替注意力可处理比全自注意力长100倍、比低秩线性注意力长3倍的信号；相比低秩线性注意力，内存占用仅需55%，推理吞吐量提升2.1倍。

实验成果：在超过25,000小时、12,000余名受试者的数据上预训练，S-CEReBrO在11项下游任务中的7项达到最先进水平，且参数量减少多达60%。

结论与开源：该工作向高效、泛化且连续的EEG监测迈出了重要一步，随附代码仓库已公开。

One Patch Is Enough: Reinforcement-Optimized Visual Token Grounding for MLLM-Based Scene Text Spotting（一张补丁足矣：基于强化优化的视觉令牌定位用于多模态大语言模型场景文本识别）

场景文本识别需要文本识别与空间定位之间的高精度对齐。视觉令牌定位虽已成为多模态大语言模型（MLLMs）的有效框架，但现有的多补丁范式常引入冗余噪声和定位模糊，尤其在密集或小文本场景中。为此，本文提出单补丁文本识别框架（SPaTS）——一个以视觉为中心的方案，通过单个锚定视觉令牌路由每个文本实例，并利用全图像精化恢复几何信息。为在无标准标签情况下准确识别该锚定令牌，引入单补丁选择性优化（SPaSO）强化学习框架，通过补丁级奖励优化离散视觉令牌选择。此外，提出方向嵌入对齐（DEA），解耦特征模长与方向以抑制不稳定范数偏差；以及补丁增强解码（PED），融合路由锚定与语言语义，并对全图像特征图进行交叉注意力，实现超越坐标空间替代方案的几何感知边界回归。广泛实验表明，SPaTS持续显著优于前沿闭源MLLM和OCR MLLM，代码即将开源。

Cybersecurity Detection Classification with Reasoning-enabled Language Models（利用具备推理能力的语言模型进行网络安全检测分类）

核心问题：安全运营中心（SOC）面临告警疲劳——每日检测量超出人员可处理范围。以往方法直接提示或微调大语言模型（LLM）输出分类标签，但未训练其推理检测是否为真实威胁。

方法：在真实人工标注的Windows端点检测数据上，结合自动提示优化、自训练与可验证奖励的强化学习，训练了一个具备思维链（CoT）推理能力的分类器。由于CoT推理会降低标签token概率（自动分流依赖此概率），另训练了一个校准器，读取完整推理轨迹并估计判定正确的概率。

结果：系统测试准确率达82.6%；在高置信度工作点（控制自动分流）下，良性召回率提升43.0%，恶意召回率提升18.3%，优于直接标签LLM分类器。研究还表明：未经训练的置信度评估器会使高置信度召回率降至零，证明校准器不可或缺；微调的30B模型显著超越前沿通用模型，说明定向训练比扩大规模更有效。

CXR-Retrieve: Compositional Text-to-Image Retrieval in Chest Radiography（CXR-Retrieve：胸片X光中的组合式文本到图像检索）

问题背景：大型胸片影像库难以检索，因为大多数检查仅配有自由文本报告而非结构化临床注解。视觉-语言模型提供了文本到图像检索的自然接口，但当前生物医学模型主要针对报告-图像匹配优化，而非满足简短临床查询，导致目标错配——模型可能检索到与查询词语相关但不满足完整临床约束的图像，尤其是对“肺不张且无肺炎”这类包含连词和否定的查询。

方法贡献：引入CXR-Retrieve，一个结构化的组合式胸片X光文本到图像检索基准。该基准包含来自MIMIC-CXR-JPG官方测试集的5,159张测试图像，以及145条涵盖单一和组合发现（含阳性和阴性）的文本查询。相关性定义基于检索图像是否满足所有断言的病理约束，而非是否匹配配对报告。

核心创新：提出一种用于临床检索的标签感知对比微调目标。该方法吸引具有兼容病理约束断言的图像-文本对（包括共享的确认阴性），同时明确排斥矛盾对。基于领域内CXR-CLIP检查点，该方法在双病理组合查询上比CXR-CLIP提升Precision@5达8.5个百分点，在否定查询上提升22.0个百分点。

关键结论：可靠的胸片X光检索需要建模不仅包含哪些发现被提及，还包括其临床断言方式的训练目标。

MonoVoc: Decoupling Geometry and Semantics for Lightweight Monocular Open-Vocabulary 3D Gaussians（MonoVoc：解耦几何与语义的轻量级单目开放词汇3D高斯方法）

核心贡献：提出一种免训练的全新流程，将3D几何重建与语义集成彻底解耦，输入为普通单目视频，输出紧凑、可解释、可搜索的对象级语义高斯地图。

技术要点：在制图循环中独立提取几何，通过轻量模块化后处理框架完成语义落地，避免将重型语言嵌入与制图绑定。

主要优势：在Replica数据集上保持强渲染保真度和有竞争力的分割精度；以模块化对象级语义嵌入替代密集逐高斯存储，内存消耗较SOTA基线降低一个数量级。

应用价值：为直接基于日常单目视频的开放词汇3D检索和问答提供高效、可扩展、实用的解决方案。

From Single- to Cross-Document: Benchmarking Multi-Granularity Event Analysis of Large Language Models（从单文档到跨文档：大语言模型多粒度事件分析基准测试）

核心摘要：事件分析是信息抽取的基础方向，涵盖文档不同粒度上的多种事件中心任务。现有大语言模型（LLMs）虽在部分任务上表现良好，但由于现有基准在文档粒度、任务设计和数据来源上的限制，其事件分析能力缺乏全面评估。为此，本文提出MiGUE-Bench——一个系统评估LLMs多粒度事件分析能力的基准。为支撑大规模评测，作者开发了MiGUE-Pipeline，一个基于LLM驱动的自校正标注框架，可规模化获取带自动标签的高质量事件源数据。基准设计了四大核心任务：事件检测、关系推理、结构归纳和未来预测，以从原子事件细节到复杂跨文档叙事的多个层次探测模型能力。针对先进LLMs及检索增强生成（RAG）方法的大量实验刻画了当前能力边界，识别出关键缺陷，为LLMs在挑战性事件分析任务中的未来改进提供了洞见。

BlindPSNR: A No-Reference Fidelity Predictor for Low-Light Image Enhancement（盲PSNR：低光图像增强的无参考保真度预测器）

核心问题：低光图像增强（LLIE）方法通常使用固定可调参数，跨场景应用时易导致性能下降。手动选择最佳配置耗时且不现实。PSNR是自动选参的自然保真度标准，但需要通常不可用的地面真值参考。

现有局限：目前尚无基于学习的方法解决低光增强的无参考PSNR预测问题；现有替代方案（无参考图像质量评估，NR-IQA）针对感知质量而非信号保真度，且所有七个基线方法在基准测试中top-1选择准确率均为0%。

方法创新：利用配对训练数据可解析计算地面真值PSNR，无需额外教师网络。据此提出BlindPSNR——一个轻量级无参考网络，通过窗口交叉注意力融合增强图像与退化低光输入，并利用异方差回归估计PSNR。

主要结果：标量回归基线top-1准确率为54.4%，BlindPSNR提升至89.5%，遗憾值从1.62 dB降至0.026 dB，并能泛化到未见数据集（SRCC = 0.61-0.67）。

SPFM-Net: Semantic-Prior-Guided Frequency-Constrained Mamba for Invisible Watermark Attack（SPFM-Net：语义先验引导的频率约束Mamba用于隐形水印攻击）

核心问题：现有水印攻击方法依赖预定义信号处理操作或局部受限的修复网络，难以捕捉全局分布水印信号的长程依赖，导致去除效果与视觉保真度之间难以平衡。

方法创新：提出SPFM-Net，一种语义先验引导且频率约束的Mamba攻击框架。首先采用高比例掩码破坏隐形水印的空间连贯性，利用部分微调的预训练Masked Autoencoder从稀疏观测中重建语义一致图像并抑制水印信息；其次引入多尺度残差频率特征交互模块，聚合多感受野的水印残差特征并自适应抑制非水印区域响应；再通过轻量级基于Mamba的全局状态空间特征建模（GSFM）单元捕获全局水印信号的长程依赖，分离水印特征与自然图像内容并去除残余水印痕迹。

优化策略：采用多层级目标联合约束空间域、频率域和边缘域，在有效抑制水印的同时保持感知质量。

实验结果：在代表性空间域、变换域、正交矩基和基于深度学习的水印方案上广泛验证，SPFM-Net在水印攻击有效性与感知保真度之间实现了良好平衡。

TriShield: Zero-Utility-Loss Defense Against Privacy Backdoors in Federated Language Model Fine-Tuning via Orthogonal Gradient Projection and Optimizer State Entanglement（TriShield：基于正交梯度投影与优化器状态纠缠的联邦语言模型微调隐私后门零效用损失防御）

核心问题：联邦大语言模型微调虽可协作训练且不暴露原始数据，但近期攻击NeuroImprint证明恶意参数服务器可通过PEFT适配器植入隐私后门——为每个训练样本分配专属记忆神经元并限制其更新次数，从而以高语义保真度重构59%-79%的客户端训练数据。现有防御（如本地差分隐私、梯度裁剪）要么无效，要么导致不可接受的效用损失。

TriShield方法：提出三层确定性防御机制，完全阻止NeuroImprint式重构，同时实现零模型效用损失且不增加通信轮次：

1. 参数伪影检测器：在本地训练开始前识别分布式模型参数中的记忆神经元特征；

2. 有状态虚拟迭代机制：强制Adam/AdamW动量状态跨虚拟步骤不可逆地纠缠梯度，使NeuroImprint的闭式反演失效；

3. 零效用正交投影算子：将所有本地梯度更新投影到经SVD计算的主任务语义子空间，物理消除携带私有记忆的梯度分量。

理论保证：经第2、3层处理后，上传梯度与任意单个训练样本之间的互信息为零。

实验验证：在GPT-2 (117M)和Llama-Guard-3-1B上验证，TriShield将NeuroImprint重构率降至0%（涵盖所有测试攻击变体），同时保持或提升训练精度，额外GPU计算开销小于5%。

Fidelity Is Not Safety: Gently-Compressed LLMs Pass Every Data-Free Quality Guard Yet Invent Procedure Steps in Agentic Execution（保真度不等于安全性：轻度压缩的大语言模型通过所有无数据质量检查，却在智能体执行中虚构操作步骤）

核心观点：实践者通常认为，只要压缩后的语言模型通过一系列低成本质量检查（如困惑度接近原模型、MMLU等下游准确率在置信区间内、以及无数据输出保真度信号比对），即可放心使用。但本文发现这一质量检查体系存在盲区。

主要发现：在三个模型家族中，轻度压缩模型均能通过所有质量检查，但在作为智能体执行标准操作流程（SOP）时，会凭空虚构指令中从未出现的操作步骤。该效应具有算子特异性：低秩SVD截断会诱发此问题，而匹配相同困惑度的幅度剪枝则不会。

机制归因：通过对照组实验隔离出原因——压缩误差的相干性乘以其比率是关键轴，而损伤的绝对大小无法预测该效应。无数据保真度探针在设计上只能衡量保真度，因此无法捕捉这一维度。

验证方法：在三个架构上使用预注册、有统计功效的金丝雀测试，以配对置信区间刻画盲区和分离效应。算子特异性在三个架构上均复现，且困惑度检查被规避的现象出现在模型存在检查范围内低秩余量的情况下。

解决方案：提出一种无数据筛查方法：基于压缩误差的二维统计量（相干分数与误差率），以跨架构固定阈值标记失败构建，与相干性乘以比率机制相匹配。

结论：困惑度、MMLU和保真度通过不能证明智能体安全性。在智能体部署前，应对轻度压缩的低秩模型进行筛查。

Share the Judge, Learn the Deferral: Where Specialization Helps LLM Evaluation（共享评判，学习延迟：专业化在何处助力大语言模型评估）

核心问题：智能体系统拉大了“产出候选答案”与“评审答案”之间的差距。本文探讨一个架构性实践问题——领域专业化应内置在评估器的权重中，还是内置在决定其判断何时可被信任的规则中？

关键发现（基于99,952个公开的、带评分标准的样本）：

1. 评分标准对准确率的影响显著：提供正确评分标准可使锁定测试准确率比仅回复对照组提高2.11个百分点；替换为无关评分标准则损失2.66个百分点。

2. 权重层面专业化有损性能：将相同训练语料分配给八个按标准族划分的LoRA评判器，准确率反而下降10.05个百分点，且在5%风险目标下的可审计覆盖率从24.44%降至5.43%。用单个秩-64适配器匹配同等存储容量并不会重现此损失，且该结果与学习率或优化器步数无关。

3. 共享初始化可修复损失：从共享的、已训练的评判器初始化各家族适配器，可将测试准确率恢复至76.85%，比同学习率下从零训练高出19.94个百分点（95%区间：18.88-21.02）。

4. 专业化转向延迟决策时效果反转：在RewardBench 2上，学习到的正确性判断头将示例路由至0.6B-4B-8B级联流程，且不改变任何奖励分数。在20次锁定重划分中，级联流程以0.415的归一化参数计算量达到89.40%准确率，而单独8B模型为84.75%。所有运行均通过精确的单侧95%风险审计；基于边际的规则保持约84.8%准确率但消耗至少0.94的计算量。

设计准则总结：在数据量足以支撑拆分之前，应共享判断的学习过程；将领域专用适配置于可审计的发布边界中。

What Makes Graph Unified? Principles and Generative Sliding-Window Transformer for Graph Foundation Models（什么使图统一？图基础模型的原则与生成式滑动窗口Transformer）

核心观点总结：

1. 图基础模型（GFM）的目标：作为通用图学习范式，旨在学习跨图领域和任务的可复用知识，减少针对特定模型的开发需求。

2. 关键挑战：节点特征的异质性（维度与语义差异大）是输入层面的根本障碍；现有方法仅将特征映射到固定维度空间，但维度统一≠语义统一，无法确保跨域可迁移性。

3. 四原则提出：跨域图特征统一需满足四个要求——形式统一性、跨域可迁移性、信息保留性和骨干兼容性。

4. 方法创新（SliGFM）：基于拓扑感知的滑动窗口特征编码与生成式重建；按拓扑平滑度排序特征维度，用共享滑动窗口编码器扫描重排序后的特征，生成有序的固定维度特征标记。

5. 核心机制：平滑度感知的Transformer捕获节点内特征标记间的可迁移关系模式；生成式重建目标保留原始特征信息。

LEDGERMIND: Provenance-Constrained Multimodal Agentic Reasoning with a Structured Evidence Ledger（账本思维：基于结构化证据账本的来源约束多模态智能体推理）

核心问题：多模态视觉问答智能体虽已发展为多步推理轨迹，但评估仍主要依赖最终答案准确率，无法区分答案是基于可靠证据、语言先验还是错误抵消所得。

提出方案：将多模态智能体轨迹视为受来源约束的状态机——工具输出被标准化为“结构化证据账本”作为轨迹状态；下游推理与决策仅可引用活跃账本条目；接地性检查在实体与数值层面进行；修复通过类型化状态转换实现，且不得引入无工具来源的内容。该设计被实例化为LedgerMind系统。

核心组件：三层接地协议、自适应双路径调度器（匹配推理深度与问题复杂度）、事件触发验证与修复引擎（具备形式化的来源非放大保证）。

针对缺陷：LedgerMind旨在解决最终答案准确率常掩盖的四类重复性失败模式：无支撑的中间推理、引用支撑的实体幻觉（幻影接地）、简单查询上的过度推理、以及修复阶段的放大问题。

实验结果：在多个多模态推理基准与骨干MLLM上，LedgerMind同时提升了答案准确率与轨迹级忠实度。

ZAPs: A Reward Attribution Framework for DeFi Ecosystems with Adversarial-Robust Scoring via Parallel Anomaly Ensemble Detection（ZAPs：一种面向DeFi生态系统的奖励归属框架——通过并行异常集成检测实现对抗鲁棒性评分）

核心问题：DeFi激励计划常依赖原始交易量、交易笔数和钱包数，易受机器人和女巫攻击（Sybil操作）影响。

关键发现：干预并非产生平稳缓解，而是导致双向偏见失稳——由于BiasScore无符号，候选集混合了推动和抑制刻板印象的神经元，总体偏见的净效应取决于哪一方向占主导。

本文探讨了人工智能在物理学发现中的角色及其局限。核心观点指出，AI加速了物理学发现，但可能偏离了爱因斯坦级别的理论构建。一个显著趋势是：AI对物理学发现最突出的贡献，似乎以相反的次序重演了物理学史——人类物理学发展从古代模式预测，到开普勒式现象学定律，再到相对论和标准模型等基于原理的普遍理论；而AI的贡献则反向而行：早期里程碑强调符号回归等显式方程发现方法，近期前沿成果如AlphaFold和GraphCast则是强大预测器，虽极准确但缺乏清晰理论理解。若此趋势持续，AI将极擅预测，却难以提出量子引力等范式级理论的严肃候选方案。文章指出了一个关键缺失能力：提出正确问题、发明正确原理以指导新理论发展及设计证伪测试的能力——这正是17世纪以来最深刻物理学进步的驱动力。赋予AI此类技能，可使其从在已知框架内预测，跃升至提出下一个范式级物理学发现。

Metaphor Tracer: A Theory-Informed Analysis of Hidden States（隐喻追踪器：一种理论驱动的隐藏状态分析）

核心内容总结：

本文提出一种无需训练的隐藏状态分析方法，在前向传播中对每个词元位置的两个属性进行评分：聚合器（aggregator）衡量该位置是否将整篇文本整合为稳定配置；分化器（differentiator）则检测模型阅读时其他词元是否被暂时携带进入其子空间——即隐喻本义的“运输”。所有常量均基于一篇发现性文本冻结，其余文本均为验证性测试。

关键发现：

聚合器并非传统意义上的信息度量或显著性度量。在三个互不相关的模型中，当某个能指重复出现时，其惊异度（surprisal）和注意力均下降，但聚合器分数保持不变——这一通道标记了词元在文本中的位置。该指标追踪阅读过程有独立事实依据：一个工程化语域（6/6单元格）、一位精神分析学家在工具发明前对临床记录的标注（34/36单元格），且呈现分级增量，词汇控制水平之上无任何类型级度量可复现的分离效应。

迁移测试结论：

迁移测试揭示了核心性质：其词元结构随词汇类型迁移的模型，对单一话语的解读最差；在匹配的基础/指令对中，调优提高保真度但不改变类型转移。结构价值是词元在“这篇”文本中位置的属性，而非仅由其向量决定——这为隐藏状态提供了一种关系性而非本质主义的解读，将先于工具存在的理论付诸实践。
