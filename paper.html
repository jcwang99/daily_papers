ContextBias: Controlled Evaluation of Bias Persistence Under Context Shift in Text-to-Image Models（ContextBias：文本到图像模型中上下文偏移下偏见持续性的受控评估）

核心问题：文本到图像模型会学习职业角色与视觉属性之间的关联，这可能导致刻板偏见。本文探究这些关联在将角色置于不同提示上下文时是稳定存在还是会发生变化。

方法创新：提出受控评估框架ContextBias及基准ContextBench（覆盖92个职业角色、1,656个语义受控提示），旨在隔离上下文变化对角色关联视觉表现的影响。对4个最新模型生成的66,240张图像进行评估。

主要发现：将职业角色放入语义无关的上下文中并不会抑制其关联属性，反而会加剧跨角色的属性集中度（合并BI +0.047）。人口学线索、特征性服装和职业专用工具在无上下文、相关和不相关条件下均高度存在，且对语义提示改写具有稳健性。场景构成和相机取景对上下文最为敏感。

结论意义：研究揭示了一种对无上下文评估基本不可见的刻板印象持续性，强调偏见基准测试中需要进行受控的上下文变化。代码与数据集已公开。

本文对监督微调（SFT）中的关键决策进行了系统性测量，旨在揭示最优超参数选择的规律与迁移性。研究涵盖两大模型家族（Qwen3与Llama）中的稠密模型和混合专家模型，在四个真实客户SFT数据集上分别进行LoRA与全参数微调。数据集具有内置评估标准，训练数据通过迭代式SFT生成且与评估标准内部一致，确保评估结果可信。核心研究问题包括：最优学习率与批量大小如何随模型规模、家族及数据变化而变化，一个选择规则能否跨场景迁移；LoRA与全微调的性能权衡及其秩与alpha参数对可学习内容的影响；验证损失（或损失景观平坦度等指标）能否可靠反映下游任务质量；后训练收益是否随模型规模（经MoE扩展至235B参数）和数据规模而扩展；在通用指令遵循能力退化前应训练多少个epoch；以及几何感知优化器是否优于AdamW。每项建议均附有不确定性度量。

Puppeteer: Object-Grounded Posture-Aware Co-Speech Gesture Generation（Puppeteer：面向对象且姿态感知的伴随语音手势生成）

核心问题：生成与语音在时间和语义上对齐，并与周围物体空间协调的伴随语音手势仍是挑战。以往方法仅强调音频-手势对齐，忽略了姿态约束与物体交互，无法捕捉身体手势与物理空间的关联。

方法（Puppeteer）：提出一种姿态感知、物体引导的扩散模型，在因果潜空间中运行。将长手势分解为结构化图元，并通过因果变分自编码器编码为按时间排序的潜在令牌（只依赖过去信息）。随后在该潜空间中进行条件扩散，以语音信号、运动历史、初始姿态参考和物体几何为条件，生成物理一致的手势。

技术优势：时序化的潜变量表达可显式控制时间，支持手势过渡生成（in-betweening）与手势补全等任务。

评估与数据集：提出针对该任务的新评估指标；构建首个具身伴随语音手势与3D物体配对数据集SceneGes。实验表明，Puppeteer生成的手势比既有方法更多样、时序同步性更强，并能实现物体引导的手势合成。

FaceSnap: Real-Time Personalized Lightstage Facial Performance Capture（FaceSnap：实时个性化 Lightstage 面部表演捕捉）

核心问题：Lightstage 面部捕捉虽能生成工业级数字人，但资源与人力成本极高——多相机设置、数小时计算与海量数据存储构成瓶颈，严重阻碍迭代式工作流。

方法创新：本文提出 FaceSnap，一种端到端两阶段框架，大幅简化捕捉流程。第一阶段，仅需一次基于动作序列的多视角优化，即可构建融合几何与表情相关外观的个性化模型；第二阶段，该模型支持仅凭单目 Lightstage 相机即可实现高保真实时面部表演捕捉，彻底免除后续多视角采集。

附加贡献：本文还发布了 Multi4D，一个面向 Lightstage 环境下 4D 面部重建方法评估的公开基准，支持跨方法的拓扑不变几何比较。

ObserverBench: Testing Mechanistic Estimates for Intervention and Control（ObserverBench：测试用于干预与控制的机制性估计）

核心摘要：机制可解释性日益被用于指导激活引导、电路移除与安全监控等干预措施，但平均意义上准确的内部估计仍可能选择错误动作。为此，本文提出 ObserverBench——一个用于测试内部估计器（观察者）是否足以胜任其所指导的干预、控制或安全任务的基准框架。每个任务固定模型、信息边界、允许动作、决策规则、留出案例与损失函数，并分别报告估计准确性与选定动作所带来的损失。
理论与实验表明：两者均不可或缺——闭环控制中，观察者误差在起点及干预可达方向上尤为关键；在 GPT-2-small 与 Qwen2.5-7B 的电路干预任务中，成对观察者预测未见效应更准，但不一定总能选择更优动作，而基于动作损失训练的观察者则能选择更低损失的动作。
安全分诊结果：能够完美区分违规的分数在违规成本不同时，可能无法有效分配固定干预预算。在 Qwen2.5-7B、Gemma-2-9B-it 及前瞻冻结的 Qwen3.5-9B APPS 任务中，AUROC 对监控器的排序可能不同于部署损失，且最优信息源因模型而异；稀疏 SAE 读出在其报告的 Qwen 面板上也落后于层匹配的密集对照组（在披露的激活密度或检查点不匹配条件下）。
贡献：ObserverBench 提供固定任务契约、可运行基线及基于表格的提交方式，通过可实现的动作来评估可解释性方法。

核心观点总结：本文探讨了如何利用3D基础模型（如VGGT）的内部表示来从新视角推断场景中的3D信息。作者假设，为解决3D重建任务，这些模型必须学习包含大量3D场景通用知识的表示。在证明可从内部3DFM表示中解码隐藏表面后，作者提出了一种名为Z3D的方法，该方法通过对3DFM表示进行潜在扩散来估计未见视角的点图（pointmaps）。实验表明，Z3D能够在多个数据集上为新视角预测逼真的深度图。主要贡献包括：1）验证了3DFM内部表示编码了可解码的3D场景通用知识；2）提出Z3D方法，利用潜在扩散实现零样本新视角深度合成；3）在跨数据集实验中展示了该方法生成高逼真深度图的泛化能力。

Neural-Collapse-guided Task-Free Continual Anomaly Detection（神经坍缩引导的无任务持续异常检测）

核心问题：现有持续异常检测方法依赖任务边界假设，但真实工业制造环境中的数据分布偏移不可预测，任务级持续学习假设不切实际。

提出方法：将工业异常检测形式化为无任务持续学习问题，提出NC-TFAD框架——一种受神经坍缩启发的几何驱动学习方法，无需任务边界即可从非平稳数据流中学习。

技术路径：

1. 冻结预训练骨干网络，将流式特征对齐至单纯形等角紧框架（ETF）原型空间，稳定非平稳流下的表征几何结构；

2. 在无真实异常条件下生成合成异常样本作为辅助锚点，满足神经坍缩几何构建需求；

3. 引入类间/类内正则化及焦点神经坍缩对比（FNCC）损失，抑制表征漂移并增强正常-异常可分性；

4. 基于正常块原型的定位分支从正常训练样本构建校准的块级偏差图，与弱自注意力先验融合，无需像素级标注即可生成异常热图。

Detecting Object Hallucinations in Large Vision-Language Models via Cross-Modal Attention Drifts and Mask-Based Verification（通过跨模态注意力漂移与基于掩码的验证检测大型视觉-语言模型中的对象幻觉）

核心观点总结：

1. 问题背景：大型视觉-语言模型（LVLMs）中的对象幻觉问题仍是其可靠部署的主要障碍；现有检测方法仅利用单层注意力特征，忽视了跨层演化。

2. 方法提出——CADMP框架：一种轻量级对象幻觉检测框架，融合（a）相邻层跨模态注意力漂移分析与（b）针对视觉掩码的预测敏感性分析。

3. 工作原理：在解码过程中量化相邻层跨模态注意力图的分布变化以捕捉视觉接地的突变；选取漂移最大处定位视觉相关区域，并衡量掩码这些区域后的预测概率变化。两类信号互补：注意力漂移刻画内部视觉接地的稳定性，概率变化验证预测是否真正依赖识别的视觉证据。

4. 实验结果：在多个基准和代表性开源LVLMs上，CADMP持续取得具有竞争力的检测性能；消融研究证实相邻层漂移建模与掩码接地验证的互补贡献。

核心发现：多模态大语言模型（MLLMs）在联合处理语音与文本时，并未真正利用韵律线索进行语用推理，而是依赖表面的声学模式。通过在中文和英语上对Qwen2.5-Omni及Qwen3-Omni进行五种模态条件的讽刺检测评估，发现添加音频会系统性增加误报率，且无法提升真正例的检测效果。

关键机制：声学错误诊断表明，模型错误集中于一种共享的“表现性韵律”刻板印象——即高音调和不规则停顿——这偏离了两种语言中实际标记讽刺的线索。针对这两个维度的定向操纵因果性地证实了该启发式，可使误报率高达60%。

普适性验证：将同样的操纵模板直接应用于Gemini 3 Flash Preview，复制了相同效应，表明该刻板印象超越了Qwen Omni系列，并非单一模型架构的特有现象。

大型语言模型（LLMs）越来越多地利用用户上下文（如记忆、画像和角色提示）来个性化其回应。这种个性化可能影响基于证据的判断：在不同用户上下文中，相同的证据可能得出不同的结论。金融领域为研究该问题提供了高风险的场景，因为决策往往依赖于对冗长复杂文档的解读。我们使用12个LLM和3,575份SEC文件对此进行了测试，通过比较角色条件检索、中性检索和记忆框架上下文，来区分证据选择效应与解读效应的各自影响。研究发现，大多数用户上下文溢出效应源于模型在不同角色下对相同证据的解读方式差异，而非检索到的证据不同。随后我们测试了两种简单的缓解策略：将相同的投资者心态表述为用户画像而非助手角色，以及将基于证据的输出与个性化输出分离。两种策略均能减少溢出效应，但都无法完全消除，且其有效性在不同模型间存在显著差异。

核心概念：提出“隐私清洗”（privacy washing）现象，即隐私政策中承诺内容被同文件其他部分所述实践所削弱。通过四阶段检测管线（陈述提取、兼容性筛选与自然语言推理筛查、多模型法官验证、主题分析），并采用三模型LLM小组多数投票确认矛盾。

SVI2LoD3: Agent-Driven Reconstruction of LoD3 Facade Openings in Semantic 3D City Models from Volunteered Street View Imagery using Large Language and Visual Models（SVI2LoD3：基于大语言与视觉模型、由志愿街景影像驱动的语义三维城市模型中LoD3立面洞口重建）

CARVE: Verified Expansion for Variable-Length Generation in Diffusion Language Models（CARVE：扩散语言模型中可变长度生成的验证式扩展）

方法创新：提出CARVE（反事实感知验证扩展），一种免训练的可变长度解码算法。它从较短画布出发，在解码过程中动态插入额外的[MASK]位置以扩展输出；并非保留所有插入，而是通过反事实检验验证候选扩展画布——询问若额外掩码空间存在，模型对原始画布中未解析位置是否会产生相似预测。仅当插入掩码在对齐的未解析位置上引发低Jensen-Shannon散度时才予以保留，使长度增长成为经过验证的稳定性决策，而非纯粹基于置信度的启发式策略。

适用范围：无需重新训练，即可应用于全画布与分块两种扩散解码器。

主要成果：在代码生成与数学推理基准上，CARVE在所有评估模型家族中均持续优于固定长度基线；在提升准确率的同时降低推理成本，某些场景仅需固定长度解码一半的FLOPs。

VeriPhy: Agentic Physical Reasoning for World Model Evaluation and Refinement（VeriPhy：用于世界模型评估与改进的智能体物理推理）

生成视频的视觉流畅性不代表物理可靠性，单一质量分数无法指出视频违反的物理约束或失效的具体时刻。为此，本文提出VeriPhy——一个可审计的物理验证系统。该系统采用纯文本规划器，在观察任何帧之前，先将提示词编译为类型化的物理义务和经过静态验证的执行计划。执行过程中，观测仅触发并限定对冻结的底层专家模型（如分割与跟踪、计数、轨迹的十一种类型化物理测量、深度、OCR、音频事件检测）的声明式调用。每次调用返回带溯源证据的记录，其可用载荷为类型化测量值或明确标记的学习状态。类型化解算器与固定组合逻辑将可用记录映射为三值状态（支持、反驳或未知，分别呈现为合理、不合理或弃权），并附带完整溯源，使每个判定均可追溯到产生它的证据。评估基于一个包含1,500个片段、带人工标注缺陷记录的数据集，这些记录在提示词参照、空间和时间方面定位真实生成失败。在包含149个片段、304条缺陷记录的核心测试集上，VeriPhy正确识别228条，而给定相同片段和声明的已发表问题分解评估器仅识别164条。仅看召回率，VeriPhy与对同一骨干模型进行整体提示的方法（达到222条）没有显著差异；真正的区别在于，VeriPhy的每个决策都保留证据记录和溯源，使追踪可逐条审计，并可作为将批评性判定写回生成过程的接口。

Improving Argument Saliency Coverage in Small LLMs for Long Legal Opinion Summarization via Sequence-Level Distillation（通过序列级蒸馏提升小型大语言模型在长法律意见摘要中的论点显著性覆盖）

核心观点总结：

1. 方法与优势：本文证明，利用能力较强的长上下文教师模型进行序列级蒸馏，是一种简单、无需人工标注且数据高效的策略，可显著提升小型LLM在长法律意见摘要中对关键论点的显著性覆盖——而小模型在此任务中常难以保留最具显著性的论证内容。

2. 效果对比：在多个学生模型规模下，蒸馏方法持续优于基于专家撰写摘要的微调方法，体现了其在该法律意见场景中的稳定性与优越性。

3. 数据高效性：仅需约10条训练摘要即可实现大部分性能提升，凸显了教师模型生成监督信号的强大数据利用效率。

4. 蒸馏类型发现：摘要蒸馏本身足以带来显著改进；推理链蒸馏与纯摘要蒸馏效果相当，但与摘要监督结合时仅带来边际收益，未产生额外显著增益。
