Subspace Clifford Networks（子空间克利福德网络）

本文提出子空间克利福德网络（Subspace Clifford Networks），一种以分组子空间交互替代全局循环平移的重构方案。

核心方法：不在整个D维通道空间上采样稀疏循环对角线，而是将特征投影到对齐空间RD̃ = ⊕g=1G Vg，划分为G个低维子空间Vg ≅ Rk（k∈{2,3,4}）。在每个k维组内计算全部C(k,2)个楔积坐标，与SiLU激活的逐坐标乘积拼接，并在可学习的1×1线性投影之间进行分组交互，实现跨组通道混合。

效率提升：中间特征扩展从2|S|D（5次平移时通常为10D）降至1.5D̃（k=2）、2.0D̃（k=3）或2.5D̃（k=4）。

实现优化：利用固定的小组大小k∈{2,3,4}，实现融合CUDA内核，通过线程局部变量计算前向交互及基于重计算的解析反向传播，无需为逐元素中间量分配全局内存缓冲区。

架构扩展：将骨干网络从各向同性柱状布局扩展为多分辨率层次克利福德网络（Hierarchical Clifford Network），支持每阶段子空间维度可配置。

实验结果：CIFAR-100上的实验表明，所提模型在两种设置下均显著减少参数数量和训练时间，层次化变体还相较基于平移的层次化基线提升了分类精度。

在KL正则化控制下，最优策略的对数几率反映了其框架对各动作的偏好强度，因此训练后的策略承载了框架自身的偏好。部署回报等于框架上限（该框架所能提供的最佳回报）减去策略失配（因其次优决策造成的回报损失）。训练只改变失配项，而更换框架会同时影响这两项。

因此，用固定模型比较不同框架，混合了“框架本身能提供什么”和“该模型能利用到什么”两个因素。在MiniWoB++实验中，后训练使模型偏好高度特定于其训练框架：颠倒观察字段顺序不改变任何最优决策，却使训练模型的成功率从85.0%降至19.2%。

相反，被固定模型比较所拒绝但能提高框架上限的新框架，在进一步训练后表现优于原始智能体；预先测得的框架上限与失配可以预测这些收益。在Terminal-Bench Lite编码智能体框架上，用更强模型作为最优替代估计出的“上限−失配”能够复现准确率排名，而单独使用其中任一指标均无法做到。

代码见 https://github.com/2020-qqtcg/HRP。

Seeing the Options: Typed Decisions over Visual Candidates with Reusable Option Memory（看见选项：基于可复用选项记忆的视觉候选类型化决策）

本文提出Iris模型，用于处理视觉候选（如图像）的类型化决策。Jeva框架要求四个关键性质：“以上皆非”概率、候选顺序不变性、候选数量可扩展性、候选计算复用。Iris支持图像、文本或混合候选，保持决策模块不变。在基于Multimodal-Mind2Web构建的视觉候选基准（K=16，三个划分）上：独立编码准确率为78.4/72.1/74.8%，翻转率严格为零；联合编码（OneJev-4B）准确率更高（90.6/89.5/91.6%），但重排候选顺序后8-10%记录答案改变。第三种设计让每个候选在状态之后编码、但不在其他候选之后编码，严格保持顺序不变性，通过分叉缓存共享状态传递，准确率达92.1/87.0/90.2%，延迟仅为OneJev的三分之一，且具备校准的空值概率（AUROC 0.93-0.97）。让候选相互看到（集合注意力、token级读取、多向量记忆）无增益，因为视觉上不同的元素在编码器中映射为余弦相似度0.999的向量。跨请求复用图像候选在K=256时延迟降低37倍，在K=2048时降低191倍。代码：https://github.com/lllfx/Iris

TRIAGE: Efficient Vision-Language-Action Inference Needs Both Reuse and Pruning（TRIAGE：高效的视觉-语言-动作推理既需要复用也需要剪枝）

本文研究视觉-语言-动作（VLA）模型在机器人操控中的高效推理问题。VLA 模型将相机图像和语言指令直接映射为动作，但移动机械臂、人形机器人等平台需在嵌入式板卡上运行，语言骨干网络的 prefill 延迟会随每一步处理的数百个视觉 token 增长，难以满足实时性要求。

现有免训练加速方法只重计算一部分视觉 token，其余 token 要么被剪枝、要么复用其缓存的键值（KV）状态。两种方式节省的计算量几乎相同，但已有方法对每个被跳过的 token 只使用其中一种策略。本文通过 token 级诊断发现，选择哪种方式更接近全量重计算，取决于 token 的“漂移”（drift），即该 token 自缓存以来浅层值的变化程度。

在两个骨干网络上，漂移低于阈值的 token 采用复用不会比剪枝更差；但超过阈值后，复用产生的动作误差最高可达剪枝的 4.4 倍。该诊断可针对不同骨干网络校准阈值。

基于此，作者提出 TRIAGE：当 token 缓存漂移低于阈值且缓存不太旧时，认为缓存有效；在固定重计算预算下，优先重计算“重要且缓存无效”的 token，复用“缓存有效”的 token，并剪枝其余 token。纯剪枝和纯复用分别是该划分的两个极端。由于预算固定了重计算 token 数量，因此直接决定了 prefill 延迟。

在 LIBERO 和 SimplerEnv 上，TRIAGE 的平均成功率与全量重计算相差不超过 3 个百分点；在 Jetson AGX Orin 上最高可减少 48% 的 prefill 延迟；且仅重计算 7% 的视觉 token 时，在 LIBERO-Object 上比最强基线高出 24.4 个百分点。
