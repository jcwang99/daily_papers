Bytes to Threats: Byte-Sequence Transformer For Malware Detection（从字节到威胁：面向恶意软件检测的字节序列Transformer）

现有恶意软件检测方法严重依赖从可执行文件的静态或动态分析中提取的手工特征，需要专业领域知识、专用分析工具和耗时分析，限制了其在现代恶意软件日益复杂多样情况下的可扩展性和鲁棒性。因此，直接基于原始字节（包含丰富语义和结构信息）的方法日益受到关注。然而，传统静态方法和基于CNN的方法难以捕获可执行文件中的长距离依赖关系。本文提出MalwareFormer，一种基于Transformer的字节级恶意软件检测框架，直接对原始字节进行操作，无需领域知识或特征提取。MalwareFormer达到了98.35%的准确率、98.32%的平衡准确率、98.32%的宏F1分数和1.94%的假阳性率，在所有阈值相关分类指标上均优于基线，证明了Transformer为字节级恶意软件检测提供了强大且可扩展的方法。

Noise2Match: Self-Supervised Low-Dose CT Denoising via Adaptive Inter-Slice Matching（Noise2Match：通过自适应层间匹配实现自监督低剂量CT去噪）

随着深度学习的发展，有监督卷积神经网络方法显著提升了低剂量CT（LDCT）去噪性能，但需要难以获取的成对噪声-干净训练数据。经典自监督去噪方法假设像素级独立噪声，对LDCT中的相关噪声效果不佳。鉴于相邻CT切片间相似性高且噪声相关性较弱，近期一些自监督方法利用相邻LDCT切片进行训练，但这些方法未能有效处理解剖变异引起的层间非刚性错位，难以满足经典Noise2Noise框架所需的等均值条件。为此，本文提出Noise2Match，一种基于自适应层间匹配的自监督LDCT去噪方法。该方法引入层间匹配网络建模相邻切片间的标签转移过程，并对去噪器输出进行校正，以更好地满足等均值条件。理论上证明，在理想条件下，使用相邻LDCT切片训练Noise2Match等价于使用配对噪声-干净图像进行有监督训练。此外，Noise2Match还能有效完成低剂量锥形束CT（CBCT）去噪，这归功于其校正操作降低了层间噪声相关性。据我们所知，Noise2Match是首个有效的图像域自监督低剂量CBCT去噪方法。大量实验表明，Noise2Match优于现有图像域自监督方法，具有更广泛的适用性和更高的实用价值。

The Last Remote Sensing Model Built by Humans? Casting Any Earth Observation Task as Recursive Self-Improvement（人类建造的最后一个遥感模型？将任意地球观测任务转化为递归自我改进）

核心要点：地球观测（EO）模型目前仍依赖人工构建：每个新任务都需要专家设计训练方案并针对基准调优。本文证明这一循环可交给智能体完成。任何可验证的任务都可被封装为“框架”（harness）与“验证器”（verifier）：框架定义智能体可使用的资源，验证器定义何谓成功。借助标注基准、独立传感器、物理模型或同一地点的重复观测，每个EO任务都可被验证。仅需这两个组件，通用编码智能体即可构建EO模型，并基于自身输出递归改进。以往被视为独立研究问题的场景（从小样本学习到跨域适应）均转化为框架与验证器的不同选择。在涵盖光学、SAR和多光谱时间序列影像的四个EO基准上，智能体构建的模型超越了当前最优水平，且仅使用约1%的训练标签即可保持大部分精度。这为EO建立了新范式：人类设计框架与验证器，智能体构建模型，EO模型随智能体能力提升而持续改进。

Prefilling-dLLM v2: Learned Chunk Routing for Long-Context Diffusion Language Models（Prefilling-dLLM v2：面向长上下文扩散语言模型的学习分块路由）

核心问题：扩散语言模型在每个去噪步骤中对整个上下文进行双向注意力计算，导致上下文越长，单步计算成本越高。仅在推理时稀疏化不会改变预训练权重，因此模型从未在推理时所用的稀疏模式下训练过。

方法：提出Prefilling-dLLM v2，通过继续训练扩散语言模型，使其使用原生掩码标记进行路由。每个分块末尾附加一个掩码，并通过学习到的角色偏移将其标记为路由槽。在每第四层，一个查询保持双向局部窗口，并根据该掩码得分选择Top-K分块；其他层使用双向滑动窗口。

实验与结果：从Dream-v0-Base-7B扩展到16K（使用YaRN）开始，在相同布局、键预算和稠密初始化下，使用相同Fast-dLLM解码器，与双向NSA、DSA和SWA对比。将YaRN因子按评估长度缩放后，Prefilling-dLLM v2在16K至128K的所有三项RULER任务上均领先其他稀疏方法。在128K长度下，其平均准确率比次优稀疏模型NSA高7.4个百分点，而DSA和SWA接近零。在相同长度下，解码速度比全稠密注意力快172倍。

MultiAlloc: Budget-Aware Precision Allocation for KV Cache Quantization（MultiAlloc：面向KV缓存量化的预算感知精度分配）

KV缓存是大语言模型推理中内存消耗的主要来源，尤其在长上下文和复杂推理场景下。现有量化方法探索了不同压缩粒度（如逐层精度调整、逐token信息保留），但实际部署中的关键挑战并非单纯压缩，而是如何在固定KV缓存内存预算下，将有限的量化资源分配给异构的精度保留策略。为此，我们提出MultiAlloc，一种基于性能剖析的KV缓存量化精度分配框架，能够自适应地在逐层精度增强与逐token保留之间分配有限的量化资源。该框架通过轻量级离线剖析刻画层敏感性与token重要性，在固定内存约束下实现自适应精度分配；基于剖析得到的“内存-精度”权衡，无需在线搜索即可自动推导有效的精度分配策略，并在推理时应用。在推理与长上下文基准上的大量实验表明，在匹配内存预算下，MultiAlloc在Mistral、Llama、DeepSeek-Qwen和QwQ等多种模型上均持续优于逐层、逐token及最新的多粒度KV缓存量化方法。

Foundation Models for Event Prediction Across Heterogeneous Event Logs（跨异构事件日志的事件预测基础模型）

事件日志广泛存在于业务流程、制造、医疗等真实系统中，但不同系统的事件语义、标签空间、交互模式和时间尺度差异巨大，难以构建一个能直接泛化到全新系统的统一基础模型。为此，本文提出基础事件预测器（FEP），一种简单且可扩展的上下文学习架构，通过事件级非参数推断进行下一事件预测。其核心机制是：因果自注意力将上下文与目标历史分别编码为键和查询表示，观测到的下一上下文事件编码为值；交叉注意力对所有上下文转换中的下一事件结果进行基于相关性的加权聚合，使整个非参数预测过程可表达为标准注意力操作，并借助FlashAttention等现代内核高效并行化。为促进跨系统泛化，作者引入排列鲁棒嵌入学习和随机固定嵌入，将事件ID与持久语义解耦，同时采用经验分位数变换和鲁棒归一化处理多样时间尺度。FEP在696个真实事件数据集上预训练，并在50个预训练未见的留出数据集上评估。结果表明，FEP无需参数适配即可有效泛化到新事件系统，性能常接近针对各目标数据集单独训练的强模型，并显著优于现有基础模型基线，尤其在困难预测任务上表现突出。

Beyond Black Boxes: Visual Grounding for Text Embeddings（超越黑盒：文本嵌入的视觉基础）

本文旨在将文本嵌入表示为素描（sketches），主要基于三个动机：一是可视化文本表示并探索AI可解释性；二是研究基于素描的表示对信息检索的潜在益处；三是借鉴心理意象概念，探索其在推理方面的潜力。作者提出了一种基于素描的视觉基础框架，将文本表示转化为视觉地形素描，以强调文本嵌入中编码的语义内容。实验在MS-COCO数据集上进行，评估这些素描在文本检索中的效用。SBERT与基于素描的方法对比显示：SBERT在严格top-1检索准确率上仍具优势，而在top-5检索中与基于素描的方法表现相当。将SBERT与基于素描的方法级联结合后，性能优于单独使用SBERT，这表明若直接基于文本训练，基于素描的表示可能为信息检索带来显著潜力。

RAN-JEPA: An Action-Conditioned World Model for Energy-efficient Mobile Network Control（RAN-JEPA：面向节能移动网络控制的动作条件世界模型）

运营移动网络观测数据丰富但干预数据稀缺：持续产生大量被动遥测数据，而受控的动作-响应轨迹相对稀少且采集成本高昂。这种“观测-干预不对称”是构建实用RAN控制世界模型的核心障碍。RAN-JEPA通过将表示学习与干预学习分离来解决该问题：首先仅利用观测数据学习预测性潜在表示，再将表示适配到目标部署域，然后在保持编码器固定的情况下，从受控休眠/唤醒轨迹中学习动作条件潜在动力学。评估采用公开运营商性能数据进行预训练，并在真实设备四小区5G测试平台上进行域适配、后训练与控制。在未来四个15分钟间隔内，RAN-JEPA的动作条件预测误差低于GPT-2世界模型基线和机械规则，同时接近强持久性参考。假设评估表明，模型在匹配的SLEEP与KEEP计划下能产生清晰且连贯的未来轨迹。在闭环控制中，RAN-JEPA在相近拥塞成本下持续支持比两个基线更高的休眠比率。结果表明，观测优先、动作条件学习能将丰富的被动遥测与有限的干预数据转化为实用的节能RAN控制预测模型。

FlashVSR+: Efficient Video Super-Resolution via Hybrid Attention and Reward-Yield Distribution Matching（FlashVSR+：通过混合注意力与奖励产出分布匹配的高效视频超分辨率）

近期视频超分辨率（VSR）模型通过扩散蒸馏实现了高效的单步生成，但高分辨率推理成本仍然高昂，且蒸馏模型难以与人类偏好对齐。为此，我们提出FlashVSR+，从架构与训练两方面解决上述问题。架构上，基于预训练VSR模型的强局部性引入混合注意力，同时保留稀疏全局交互以保证长程一致性，实现了高达2倍的DiT加速和45%的峰值内存降低，使得在单张24GB RTX 4090上无需分块即可进行4K视频超分辨率。训练上，我们提出奖励产出分布匹配蒸馏（Ry-DMD），通过奖励加权教师采样将黑盒奖励融入分布匹配，无需通过奖励模型反向传播，从而实现偏好对齐的单步生成。Ry-DMD还可推广至文生图（T2I）任务。FlashVSR+在提升恢复质量、大幅改善高分辨率效率的同时，用户偏好一致性也持续增强。代码、模型和训练数据已发布于 www.flashvsr.tech。

Rubrics from the Task, Verdicts from Evidence: Pointwise Rubric Rewards with Tool-Augmented Judges（任务出规则，证据出裁决：基于工具增强裁判的点式 rubric 奖励）

本文提出 ReVeR，一种点式 rubric 奖励模型。现有基于 rubric 的奖励模型常从候选回答中推导标准，导致回答引入的偏差，且仅靠阅读的裁判受机械性限制，成对裁判也只提供相对偏好，难以直接用于策略优化。ReVeR 仅通过推理指令本身来推导硬性规则与分级原则，并通过工具增强的裁判独立评估回答。两个组件均通过标签盲蒸馏训练，偏好标签仅用于筛选教师输出，由此构建大规模数据集 ReVeR-Traces。实验表明，ReVeR 在平均偏好准确率上优于成对 rubric 模型，尤其在指令跟随方面表现突出，同时在测试时扩展与下游策略优化中也有优势。研究还发现，生成式强化学习提升了偏好准确率但降低了 rubric 忠实度，且更高的偏好准确率不一定带来更好的下游策略。这些结果说明 rubric 忠实度、偏好准确率与下游效用是相互独立的不同属性，为未来奖励模型研究提供了启示。

Autonomous Science Bench: Evaluating AI Agents for Autonomous Scientific Discovery（自主科学基准：评估AI智能体的自主科学发现能力）

核心内容总结：本文提出了一个用于评估AI智能体在有限预算下自主决定实验方案的基准平台——Autonomous Science Bench（自主科学基准）。与依赖固定数据集或模拟的现有基准不同，该基准基于生物学、化学和材料科学中已发表的实验，包含六项预算有限的“设计-构建-测试-学习”任务。智能体需分批选择实验设计，获取实验结果，并据此优化后续实验，最终产出预测模型。评估需通过两个独立门槛：发现门槛（衡量智能体测得的实验设计质量）和学习门槛（衡量其模型对未测设计的排序能力）。在8种智能体模型配置、144次试验的初步评估中，最佳配置的成功率为67%，最难任务仅在24次尝试中成功3次。两个门槛揭示了不同类型的失败：有的智能体构建了准确的排序模型但找到的优质设计太少，有的能找到优质设计却无法预测未知设计表现。仅看总成功率会掩盖这些差异。作者已发布v0.1版本的任务、实验运行环境及公开排行榜。

Jev-ToM: Evaluating Theory of Mind in Typed Decision Models（Jev-ToM：在类型化决策模型中评估心智理论）

对话与协作助手需要不断判断对话方的知识、信念或意图。针对有界心智理论（ToM）选择，类型化决策模型为生成式大语言模型提供了一种潜在替代方案。我们提出Jev-ToM，在来自九个ToM基准的11,117个英文文本问题（覆盖六种能力组）上，比较了五种类型化决策模型和七种生成式基线。

结果显示，TypeSafe Jev达到73.2%的源平衡准确率（含原生对照），在所有六项能力中排名第一或第二，尤其在信念、目标/欲望/意图和情绪方面领先。其他类型化模型在不同任务上各有优势。进一步的资源比较表明，Jev可降低重复ToM选择的成本与等待时间。

基于置信度的选择仍依赖于基准；提供的原因可能纠正错误或推翻正确答案，具体取决于这些原因的附加方式。候选扩展暴露了不同的选择与输出有效性问题。相关问题线索贡献了Jev下游收益的大部分，预测状态的影响因任务而异。这些发现支持在助手中将Jev作为ToM选择组件进行测试，并将任务特定的置信度校准、候选设计与输出验证作为集成优先事项。

Deficit-Driven Stratified Acquisition for Building STRATA-S12: An Open SAR-Optical Corpus for Self-Supervised Learning（基于缺陷驱动的分层采集构建STRATA-S12：用于自监督学习的开放SAR-光学语料库）

构建用于自监督地球观测的SAR-光学配准语料库，本质上是一个采集问题。现有主流多模态数据集多为机会性采集，缺乏分层配额控制，也无法应对非均匀云覆盖导致的地理缺失。本文提出缺陷驱动分层采集（DDSA）算法，将配准的Sentinel-1/Sentinel-2语料库构建视为一个在半球校正的（类别×季节×区域）分层上的约束最大覆盖问题，强制执行严格的时间配对与多阶段质量门控，并在采集过程中引入含人工反馈的缺陷修复闭环。主要结果：1）缺陷驱动排序使部分采集即具备覆盖性——预算的前几个百分点即可填充全部192个分层，而丰度优先排序会让大多数分层在采集末期仍为空；2）失败尝试能否修复取决于其成因的时间持续性，而非缺陷类型——几何缺陷（如nodata）可修复率最高（η=41.4%），云层缺陷可修复率最低（η=18.8%），因为多云地点在其所在季节的大多数日期均有云；3）修复环节贡献了39.5%的已发布配对，且质量无损，其中89.8%通过人工审查。质量保证的代价是：共2,928,370次采集尝试，最终发布740,746对。语料库STRATA-S12附带STAC/PDS4对齐的FAIR辅助文件，预注册线性探针验证表明其适用于自监督预训练。与SSL4EO-S12和SEN12MS的元数据级覆盖比较将语料库置于统一框架内；系统性的跨语料库与跨方法比较留待后续工作。

MERIT: Multimodal Evidence Reasoning over Image Tables（MERIT：图像表格上的多模态证据推理）

论文摘要总结：基于语言模型的表格推理通常假设输入是干净的文本表格。然而实际中表格常被序列化为文本，这可能导致单元格内容损坏、结构关系扭曲并丢失视觉线索，使模型在证据不完整的情况下进行推理。相比之下，表格图像保留了这些信息，但使用它们需要准确的感知能力和基于相关单元格的推理。为此，作者提出MERIT，一个三阶段框架，用于学习在表格图像上进行推理，并将序列化表格作为可选的辅助输入（如果提供）。分析表明，视觉证据获取是瓶颈，因此通过重建、定位和颜色条件监督来适配表格专用的编码器。基于适配后的表示，监督微调利用验证轨迹来教授模型显式地选择证据和进行推理。最后，强化学习分别对证据正确性、计算、最终答案和输出格式设置奖励来优化策略。通过对中间步骤提供反馈，该框架能够针对仅依靠最终答案监督无法区分的检索错误和计算错误。研究在表格问答和事实验证任务上评估了该方法，分析了视觉输入和训练组件的贡献，并评估了在不同表格结构和视觉呈现方式下的额外数据集上的泛化能力。

ACCRUE: Continual Off-Policy Reinforcement Learning for Robot Foundation Models（ACCRUE：面向机器人基础模型的持续离策略强化学习）

强化学习（RL）后训练能提升机器人基础模型（RFMs）超越演示的能力，但实际部署要求更高：在高效学习新任务的同时保留先前习得的行为。现有的基于视觉-语言-动作模型（VLAs）的持续RL方法虽能缓解遗忘，但依赖在线策略更新，前向迁移有限；离策略方法虽提升单任务样本效率，却未解决跨任务的持续学习问题。我们提出ACCRUE，一种持续离策略RL框架，跨任务携带轻量演员-评论家网络，使每个阶段复用先前RL获得的行为与价值知识。继承的评论家仅基于当前任务转移进行适应，并指导当前任务演员学习；同时通过将演员蒸馏到少量保留片段上的缓存目标来保留先前行为。固定视觉特征使继承学习器及其回放与基础策略更新兼容。在仿真和真实机器人硬件上的接触丰富装配序列中，ACCRUE加速后续任务学习，几乎零遗忘，并将真实机器人训练时间显著减少31.0%至68.5%。

Claim Framing as a Driver of LLM Sycophancy（主张框架作为大语言模型谄媚行为的驱动因素）

大语言模型中的谄媚行为（即倾向于迎合用户偏好而非事实真相）以往研究多基于无明确正确答案、且仅包含单一直白用户观点的问题。本文系统研究了在事实性问答中，用户主张的不同表述框架如何触发谄媚行为——此类问题中每个答案均可客观验证，无需额外背景。研究评估了14个模型、42K个问题，通过8个维度、21种类型的不同主张框架来表达正确或错误的用户观点，并测量多种观点驱动行为。研究发现：所有模型无论规模大小都易受用户观点影响；模型最受观点陈述的自信程度、观点归属对象、以及观点是否被呈现为“用户与模型共享”的影响。与以往研究不同，在事实性问答场景中，基于用户专业性、对模型的权威性或社会压力的框架影响甚微。较大模型更能抵抗错误观点，但在从自身错误中恢复方面并无优势。研究结果呼吁谄媚评估不应仅检验是否存在观点，还应探究观点如何被表述，并测量除单一翻转率之外的多重行为。

PaceReasoner: Label-Free Learning to Answer Briefly from Long Reasoning（PaceReasoner：从长推理中无标签学习简洁作答）

核心贡献：提出PaceReasoner，一种无标签的测试时强化学习框架，利用模型的长推理（LONG）回应来提升其短推理（SHORT）模式的准确率，从而在减少推理成本与延迟的同时保持高性能。

关键机制：两种模式共享可训练策略；通过全回应与仅长回应的答案共识，结合渐进式置信加权监督；行为奖励从鼓励短回应探索逐步过渡到奖励与长答案一致；比例控制器动态调节两种模式的平衡。

主要结果：在三种模型骨干和四个基准上，平均短回应准确率超过基线7.4–13.5个百分点，且平均每个回应少于25个推理token；消融实验验证关键组件有效性，跨数据集结果证明超出适应集的迁移能力。

LatentRiskBench: Measuring State-Dependent Risks in Enterprise Agents（LatentRiskBench：评估企业智能体中的状态依赖风险）

企业智能体面临的安全风险无法仅通过单个动作判断。现有安全基准大多评估动作层面的局部风险，忽视了依赖工作流状态的安全故障。此类状态依赖风险中，同一动作在一种情境下可能安全，在另一种情境下却违反策略。为此，作者提出LatentRiskBench，用于评估企业场景中的状态依赖风险。该基准将风险轨迹与良性轨迹配对，二者共享相同的最终动作，但潜在策略相关状态不同，从而要求模型重建工作流上下文，而非依赖动作级线索。作者还引入了新的状态依赖风险评估指标，包括一组残差风险（RR）度量。实验表明，动作级评估仅能检测出0.09的状态依赖违规，而状态级评估可达0.96。现有护栏方法若未显式应用于工作流状态，则大多会忽视此类风险。在商业部署场景中的案例研究进一步表明，基准中嵌入的安全指标能为企业智能体提供更现实的安全度量。数据集和代码见：https://github.com/JingyueCong/LatentRiskBench。

MIST: Multi-Scale Spatial Context for Gene Expression Prediction from Histology（MIST：用于组织学基因表达预测的多尺度空间上下文）

标准Transformer对点进行自注意力计算，但忽略了点在组织中的空间位置；而点的分子状态依赖于多个空间尺度的组织上下文。为此，作者提出MIST——一种多上下文空间Transformer，它在每一层的自注意力主干上增加了两条上下文通路：一条是坐标不变的局部通路，关注空间k近邻点；另一条是切片级通路，将整张切片的摘要信息广播到所有点。模型通过一次前向传播即可预测所有点的表达。由于坐标仅通过成对距离进入模型，在图像特征固定的情况下，局部通路对平移、旋转和反射具有不变性。

在HEST-1k的六个人体器官队列内部评估中，MIST在10、50和100基因panel上的平均Pearson相关系数分别比最强基线提升9.7%、11.6%和11.4%，同时平均MSE和MAE最低。在跨器官迁移评估中，MIST比次强基线提升6.0%，并取得最佳的表达派生域恢复性能（在所有聚类分辨率下平均ARI和NMI最高，且在84%的留出切片上NMI高于最接近的基线）。此外，MIST还能重现选定癌症标志基因的空间表达模式。

综上，在普通Transformer主干上添加局部和切片级上下文，是一种有效的组织学基因表达预测方法。

Deterministic Prediction as Global Velocity: Flow Matching for Probabilistic Time-Series Forecast（确定性预测作为全局速度：用于概率时间序列预测的流匹配）

不确定性量化对时间序列预测至关重要，近期研究越来越多地采用生成模型来捕捉预测不确定性。现有方法常将确定性预测与生成建模结合以提升性能，但由于确定性模型嵌入生成过程，导致计算图过深且改变概率传输路径，联合训练往往不稳定。为此，我们提出DV-Flow，一种统一的流匹配框架，将确定性预测器作为并行速度分量而非传输路径终点。该设计实现了稳定的端到端优化，并将多种现有公式作为特例纳入，便于直接比较。在六个真实数据集上的大量实验表明，DV-Flow持续优于强基线，显著提升概率预测性能。代码已开源：https://github.com/tufts-ml/dv-flow-time-series。

One-Sided Verification Under Limited Expert Review（有限专家评审下的单边验证）

人工智能在科学发现中日益重要，但在缺乏可靠自动评估的问题上，人类专家评审仍不可或缺。随着候选方案数量超出评审能力，验证成为关键挑战。本文研究有限人力下的验证问题：优先找出稀有正确方案，同时过滤无效候选以减少人力负担。作者提出单边验证目标：在限制有效方案误拒率（FNR）的前提下，最大化无效方案拒绝率（TNR），将人工评审成本作为显式最小化项。基于“验证具体错误比发现错误更容易”的直觉，提出OSVerify框架，将错误提议与错误验证解耦：提议器通过层次分解在不同粒度搜索错误，验证器区分实质性错误与次要或幻觉错误。在竞赛级和研究级基准上，与投票基线相比，OSVerify在相同经验低FNR约束下平均减少46%的无效方案人工评审；对验证器进行后训练后，该比例进一步提升至57%。实际应用中，OSVerify成功识别出已发表论文中的错误（得到原作者确认），并帮助解决了三个Langlands开放猜想（经专家确认），展示了其促进人机科研协作的价值。

Two Routes to Interoceptive Prioritisation: Dissociating Likelihood Precision and Preference Reweighting in Active Inference（内感受优先化的两条路径：主动推断中似然精度与偏好加权的分离）

一个有具身能力的智能体必须在相互竞争的躯体需求中做出优先排序。在主动推断框架下，它可以通过提高关于该需求的信息精度，或增加对能够缓解该需求的结果的偏好，来回应紧急需求。我们在一个具有三种致命需求的觅食网格世界中，分别及联合比较了这两种干预方式，并考察它们如何改变生存率、感知以及智能体习得的身体模型。精度会锐化内感受后验并提高生存率；偏好加权则使身体状态更远离致命边界，并改变了智能体学习时所处的状态，因此其习得模型覆盖的需求水平更少，在所有水平上的质量较低，但在其访问的水平上质量略高。在72种额外布局上的实验未能证实预期中偏好加权在困难布局上的收益，但两种干预都提高了这些布局中的平均生存率，且它们之间存在正向交互作用。因此，仅凭生存率无法完整解释模型如何对需求进行优先排序并学习关于自身身体的知识。

Configuring RAG Systems: What Breaks, Where Originates, and How to Fix（配置RAG系统：什么会出故障、源自何处及如何修复）

检索增强生成（RAG）已成为通过与其他组件（如向量/图数据库）结合来改进大型语言模型（LLM）的主导范式。由此产生的RAG系统通常高度可配置，不少故障与配置相关，但学界对其配置问题缺乏系统性理解。为此，本文首次对来自10个不同RAG系统的654个真实配置问题进行了大规模实证研究，给出了症状、根本原因、相关阶段和修复模式的完整分类，并提出若干新观察。研究发现，大多数症状可在流程早期或晚期观察到，而根本原因所在阶段可能与症状识别阶段并不一致。此外，文章为RAG系统配置问题的测试、定位和修复提供了九项可操作建议。

High-fidelity Three-dimensional Flow Field Reconstruction Driven by Turbulent Fluid Dynamics（基于湍流流体动力学驱动的高保真三维流场重建）

高保真三维湍流流场对科学与工程分析至关重要，但直接数值模拟或高分辨率测量成本高昂。从粗粒度数据中进行超分辨率重建是一种有前景的替代方案，但由于细尺度结构本质上具有三维性且跨尺度动态耦合，重建极具挑战性。现有数据驱动方法难以恢复多尺度体积结构及其相干时间演化。为此，我们提出一个湍流感知框架，用于时间分辨的三维流场重建。该框架耦合多尺度神经算子以恢复体积结构，并结合状态空间模型增强重建动力学的时间一致性。此外，引入Navier-Stokes残差作为软约束，将重建正则化至物理上合理的动力学过程。还采用专家混合机制支持对未知粗粒化的无监督自适应。在典型湍流系统和大气再分析数据上的评估表明，该框架相比学习和经典基线方法降低了重建误差，同时更好地保留了多尺度空间结构和相干时间演化，验证了其从粗粒度数据重建高保真三维流场的有效性。

ECMR: Evidence-Aware Deliberation Control for Multi-Agent LLM Reasoning（ECMR：面向多智能体大语言模型推理的证据感知协商控制）

多智能体大语言模型系统通常在推理前就确定协商协议，但固定协议无法对不同难度的实例差异化分配计算资源，并可能将重复支持误认为独立确认。本文将此类失败定义为“语义性虚假共识”：即小组答案看似自信，实则依赖于狭窄、重复或相关的理由。为此提出ECMR——一种基于证据感知的控制器，作用于固定角色的LLM之上。每一步中，ECMR综合评估答案集中度、支持多样性、独立性、矛盾、角色行为、验证历史及剩余预算，并动态选择下一步行动：提出、质疑、验证、仲裁、多元化、纠正角色或停止。该决策被建模为有限时域预算控制问题，并推导出状态条件化、风险触发验证和角色纠错可提升成本调整效用的充分条件。在MedQA、CaseHOLD和FinQA共9000条记录的保留评估中，ECMR-Full将池化准确率从62.1%提升至84.9%，虚假共识率从40.7%降至17.0%，证据支持率从58.0%提升至88.7%。状态洗牌导致准确率下降11.7个百分点，而轮次仅减少0.7；更难的轨迹则从早期停止转向仲裁。ECMR-Full使用最大token预算，获得最强的绝对可靠性，而非统一的token效率优势。

A Node Embedding Framework for Model-Centric Conformance Checking in Process Mining（一种用于流程挖掘中模型中心一致性检查的节点嵌入框架）

流程挖掘中，评估从事件日志发现的过程模型质量是一个基本挑战。传统评估依赖适合度和精确度等一致性指标，但这些指标对日志中的噪声和偏差高度敏感，往往无法对发现算法给出稳定评估。本文提出一种以模型为中心的评估框架，结合节点嵌入与Procrustes对齐实现跨图可比性（因为不同图生成的嵌入位于不同向量空间）。所提出的PetriNetGraph方法将Petri网过程模型转换为兼容嵌入算法的图表示。通过参数化余弦距离比较真实模型与发现模型的节点嵌入，得到一个统一且有界的度量，用于跨数据集和方法评估过程发现效果。作者在静态和上下文感知场景下评估该框架，以考察活动存在性的先验知识如何影响结构相似性评估。该框架还集成了合规检查机制，可在活动层面定位偏差，并通过熵正则化节点距离聚合函数量化模型整体偏差。在九个公开事件日志上的实验表明，该方法提供了可靠的基于嵌入的一致性指标，能够反映适合度和精确度的行为。在受控噪声水平的合成日志上的实验证实，该方法相比传统一致性指标、PetriNet2Vec及其动态窗口和Procrustes对齐变体，对日志偏差具有显著更强的鲁棒性，同时保持对过程模型退化的敏感性。所有实现细节和数据集均已公开。

Understanding Gene Expression-to-Image Learning: Spatial Structure and Information Fidelity（理解基因表达到图像学习：空间结构与信息保真度）

单细胞RNA测序（scRNA-seq）可实现细胞水平的生物异质性分析，但从高维、无序的基因表达谱中学习有效表征仍具挑战性。基因表达到图像（GE2I）通过将基因值排列在像素网格上以适配卷积神经网络，是一种有效学习策略，但其内在机制尚不明确。本研究在固定网络和训练流程的条件下，基于全转录组数据研究GE2I，揭示了空间平滑性与基因级保真度之间的权衡：结构化映射产生平滑、低频模式，有助于早期快速优化；而将多个基因分配到同一像素会模糊表达差异，可能降低预测性能。该权衡解释了为何在表示大量基因时，随机映射能与结构化布局相媲美。在测试的多种视觉骨干网络中，一对一基因到像素的分配均提升预测性能，即使图像平滑度下降。研究还发现，预训练与数据增强的收益取决于骨干网络和映射方式。这些发现为像素分配及将视觉先验迁移至基因表达数据提供了实践指导。

Over-parameterization Is Neither Robust nor Fragile in Matrix Sensing: A Geometric Theory of Solution Robustness（矩阵感知中的过参数化既非稳健亦非脆弱：解稳健性的几何理论）

过参数化在现代机器学习中普遍存在，但其对稳健性的影响尚不明确。本文在矩阵感知这一经典非凸问题中研究该问题，该问题在适当参数化下也可视为训练两层二次神经网络。针对Burer-Monteiro分解，作者发展了秩感知的稳健性理论，允许搜索秩k超过目标秩r_star，从而刻画过参数化。分析表明：稳健性取决于过参数化程度与所得二阶稳定点的局部几何性质——增大k通常会降低敏感性，但相同搜索秩的稳定点可能表现出截然不同的稳健性。基于此，作者提出了一种轨迹感知算法，利用谱平衡和随机素描将优化引导至敏感性更低的解。在矩阵感知实验中，该方法在保证重构精度不降的前提下，对各向同性算子的成对敏感性降低18%-29%，对弱尾算子降低87%-89%。结果表明，参数数量本身并不决定稳健性，解几何与优化轨迹是提升稳健性的重要杠杆。

Self-Evolving Agent Harness（自进化智能体框架）

该框架通过更新智能体的软件脚手架（包括提示词、记忆、工作流和可执行组件）来实现自进化，同时保持模型权重固定。其核心是一个反馈驱动的过程，被接受的修改会在多次运行中持续保留。框架将更新目标与提议及接纳机制相分离，并区分对解释性状态的修改与对工具和代码、仓库级控制逻辑、插件组合的修订。研究通过进化优化刻画搜索过程，并借助持续PAC学习检验其可靠性。在明确假设下，分析得出了预期泛化界、基于历史回归预算的保留界，以及使用全新独立验证数据的高概率接纳规则。本文还探讨了持续性的框架修订对知识共享和组织工作流的影响，及其对科学可靠性、物理安全和机构问责制的意义。已有案例展示了模型与框架协同设计、分布式执行和插件复用。可靠部署需要随着任务分布和评估器变化进行持续验证，并对学习过程、运行时权限和重大后果性行动设置独立保障。论文提供了66页的全面讨论，涵盖相关工作、理论、算法、评估、应用以及Harness RSI的更广泛影响，并附有持续更新的代码和补充材料，见 https://github.com/zgcagi/Harness-RSI。

Beyond Answer Voting: Fine-Grained Correction of LLM Reasoning through Graph Alignment across Sampled Traces（超越答案投票：通过采样轨迹中的图对齐实现大语言模型推理的细粒度修正）

大型语言模型在处理多步推理任务时，中间步骤的错误可能影响最终答案。自一致性（SC）通过对采样得到的最终答案进行投票来提升推理性能，但投票过程无法解决中间推理步骤的分歧。为此，本文提出DDRG（基于推理图的分歧驱动验证）框架，从固定的推理轨迹库中进行选择性修正。核心思想是：图对齐能够揭示声明层面的分歧，并在不扩充采样轨迹库的情况下提供修正证据。DDRG构建基于来源的声明图，并将局部冲突发送给一个不依赖答案的验证器。若验证器对多数答案支持路径的反驳成立，则触发一次有针对性的修复；否则，DDRG返回与SC一致的投票结果。在五个基准上的实验表明，原生零样本DDRG在宏观平均准确率上，相比直接回答，对Qwen2.5-7B提升8.65个百分点，对Llama3.1-8B提升15.83个百分点；同时在该宏观指标上超过了CoT、所评估的GoT与GoV问答适配版本以及SC。DDRG将局部验证与选择性修正相结合，且无需扩大初始候选库。
