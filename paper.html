Diagnosing Tool-Selection Reasoning in LLM Agents with Canary Tools（利用金丝雀工具诊断LLM代理的工具选择推理）

核心问题：现有的智能体评估只能告诉我们模型选错了工具，却无法解释选错的原因。为此，研究者提出“金丝雀工具”（canary tools）——一种植入在智能体Model Context Protocol（MCP）工具集中的诊断性探针工具，每种工具专门探测一种特定的工具选择缺陷。

方法：提出六类缺陷分类体系：语义诱饵、参数陷阱、能力幻象、前置条件盲区、时间诱饵、粒度陷阱。这一分类将单一的“选错工具”结果转化为模型工具推理模式的多维画像。实验覆盖8个模型（6个托管模型、2个80亿参数开源模型）、三个能力层级、120个任务、三种金丝雀密度条件和三种随机种子（共8640次运行），另加2880次消融实验。任务成功由独立裁判评估，并经第二裁判验证（Cohen's kappa=0.75）。

主要发现：（1）模型能力越强，金丝雀易感性越低——各模型的任务金丝雀易感率（CSR）相差约36倍，Claude Opus 4.8最低，Llama 3.1 8B最高。（2）能力层级不能单独预测安全性——最易受影响的托管模型处于中等级别，且同一供应商内更便宜的模型可能更安全。（3）分类体系具有能力分层特征：能力幻象最能稳定困住前沿模型，而其他类型对强模型基本无效、但对小型开源模型有效，因此它们按能力区分而非一刀切。

稳健性验证：软化每个金丝雀的提示性措辞后，前沿模型的CSR基本不变，证明探针测量的是推理能力而非关键词识别。易感性还能预测任务失败（Spearman rho=-0.34），而最稳健的模型不受金丝雀压力显著影响。研究者已发布全部框架、金丝雀模式、任务和日志。

The Sample Complexity of Distributionally Robust PAC Learning under Cressie--Read Divergences（Cressie--Read散度下分布鲁棒PAC学习的样本复杂度）

本文研究了0-1损失函数下的分布鲁棒PAC学习，其中数据分布的对抗扰动受Cressie--Read散度（阶数k>1）和半径ρ≥0约束。针对VC维为d的假设类别，分别建立了可实现（realizable）与不可知（agnostic）情形下紧致到常数因子和对数因子的样本复杂度界；普通经验风险最小化即可达到这两个速率（至多相差对数因子）。对于目标精度ε∈(0,1)和置信度δ∈(0,1)，其样本复杂度阶分别为max{1/ε, ρ^{1/(k-1)}/ε^{k_*}}·(d+log δ^{-1})（可实现情形）和max{1/ε², ρ^{1/(k-1)}/ε^{k_*∨2}}·(d+log δ^{-1})（不可知情形），其中k_*=k/(k-1)。关键发现：对任意固定ρ>0，当ε→0时，鲁棒性将可实现情形的ε依赖性从ε^{-1}变为ε^{-k_*}；在不可知情形中，当k<2时ε依赖性为ε^{-2}，当k>2时变为ε^{-k_*}。此外，本文给出了该依赖性的信息论下界，证明其在可实现情形下紧密，在不可知情形下（k>1时）缩小了上下界差距，并且当ρ→0时恢复标准PAC学习速率，而此前界在该极限下无法正确插值。

MultiPathFormer: Towards a Foundation Model for Multipath Wireless Propagation（MultiPathFormer：面向多径无线传播的基础模型）

核心观点：现有无线基础模型通常在子载波、天线或时间维度上进行掩码重建预训练，忽略了无线传播的物理特性。本文提出以多径传播作为基础预训练对象，构建自回归基础模型MultiPathFormer，将每条收发链路表示为连续路径令牌的有序序列，并通过下一路径预测进行预训练。

主要创新：1）引入环境检索增强生成（Environmental RAG）机制，利用环境知识提升路径统计量（如时延和功率）估计精度最高达59%；2）在Transformer骨干上增加首路径码本（first-path codebook）。

结论：路径级预训练能够学习到无线传播的可复用表示，验证了以物理传播特性为预训练对象的有效性。

激励广告通过提供货币或虚拟奖励来驱动用户参与，其核心挑战在于严格全局约束下优化连续激励幅度。该问题因高频交互、延迟反馈以及疲劳效应等非马尔可夫用户动态而变得复杂，限制了现有提升建模和约束强化学习方法的有效性。为此，我们提出GOAL框架，一种将激励分配建模为条件序列生成问题的约束感知生成式框架。GOAL直接基于用户历史和系统级全局压力生成激励幅度，并集成层次化因果状态编码器以捕获局部行为动态和长程依赖。为实现灵活的约束控制，我们引入安全约束策略优化（SCPO），该方法学习单一生成策略，可在无需重新训练的情况下泛化到不同ROI约束范围。在大规模真实数据和合成疲劳感知环境上的实验表明，与强基线相比，GOAL在显著降低ROI违反率的同时，提升了长期收入和用户留存。

核心问题：微调能让源模型在目标领域获得新能力，同时保留通用性，但也可能削弱源模型原有的对齐属性（安全性/价值观对齐）。现有 introspection adapter（IA，内省适配器）研究主要针对“显式植入”行为的解释，而实际部署中更关键的是副作用性对齐偏差——即在与安全无关的任务上微调导致的意外对齐退化，现有方法难以覆盖此场景。

新问题定义：作者提出“副作用内省”（side-effect introspection）——内省目标不是微调显式植入的行为，而是作为意外副作用出现的对齐偏移，并为此构建了专属数据集。

技术贡献：提出Delta-Aware Introspection Adapter（DAIA，增量感知内省适配器），该机制显式处理基础模型激活与微调引起的激活差异，从而增强对内部模型变化的敏感性。

实验结论：实证评估表明，内省学习可泛化至未见过的微调模型及安全类别，且DAIA在性能上持续优于现有内省适配器。

An Analysis and Implementation of Seam Carving for Content-Aware Image Resizing（接缝雕刻用于内容感知图像缩放的分析与实现）

接缝雕刻是一种经典的内容感知图像缩放算子，通过反复移除（或插入）接缝，即局部重要性最小的8连通单调像素路径，来改变图像宽度或高度。由于接缝绕开显著内容而非均匀缩放或裁剪，该算子能保留关键图像结构，同时丢弃（或复制）低能量区域。本文描述了遵循Avidan和Shamir（2007）原始公式的C++实现，包括Rubinstein、Shamir和Avidan（2008）随后引入的可选前向能量准则。该实现支持图像缩小、通过有序接缝插入实现图像放大、针对大比例因子的多遍放大、用于物体保护与移除的用户指定权重掩码，以及能量图导出和接缝可视化。文章详述了算法、参数和计算复杂度，讨论了与原始描述相关的设计选择，并展示了该算子在自然图像上的行为表现。

核心问题：现有视频模型虽支持生成、参考条件控制和编辑，但将其视为固定输入上的独立操作，无法满足多镜头、需共享历史信息的实际创作需求。本文将其形式化为“交互式多镜头视频创作”（IMVC）。

方法创新：提出统一模型ContextMaster，采用角色感知的上下文表示，并通过可复用的干净上下文状态+固定预算稀疏上下文路由控制每次去噪步骤的上下文读取成本；引入ConstraintSink保持任务约束可见。

训练框架：针对稀疏上下文访问与少步推理的双重挑战，提出两阶段特权上下文蒸馏框架——先通过一致性蒸馏从密集教师模型迁移完整上下文行为，再用分布匹配优化部署时的生成轨迹。

AFD-Ledger: Deployment Provisioning for Attention--FFN Disaggregation（AFD-Ledger：面向注意力-前馈网络分离的部署配置）

注意力-前馈网络分离（AFD）正成为一种服务混合专家（MoE）语言模型的有前景架构。现有AFD系统虽提升了分离执行的效率，但遗留了一个部署问题：在相同模型、工作负载、每输出词元时间（TPOT）服务级别目标（SLO）、硬件预算、硬件目录和运行时能力下，AFD是否比最优共置部署提供更高的吞吐量？回答此问题需对两种架构联合优化硬件分配与部署组织，使得穷举式配置代价过高。我们提出AFD-Ledger，一个离线分析式配置系统，利用分析执行模型和评估有界硬件搜索，独立配置AFD与共置部署。在可穷举配置的部署空间中，AFD-Ledger将完整部署评估减少68.8%–83.5%，同时仍能恢复全局最优部署。在三个物理LongCat 2.0部署上，它保持正确的架构决策，同时预测AFD与共置部署的吞吐量误差在实测值的6.6%–9.6%以内。利用该验证框架，我们表明：同构AFD仅在少数研究设置中提升固定预算吞吐量；异构AFD需要部署级硬件互补性而非启发式设备选择；角色特定的硬件改进主要在其通过跨越部署能力-价格边界促成更优部署组织时才有意义。

关键机制：评估者反馈表征可靠性和生产力，更新角色级效用，并将精英模式、失败轨迹和有效性诊断路由至不同智能体；框架在两个时间尺度自进化——运行内自适应搜索过程（不更新LLM参数），运行间将记录轨迹蒸馏为开源LLM的角色条件提议先验。

核心问题：腰椎MRI退行性病变的自动分级依赖大量专家标注的放射学分级标签，成本高昂；而分割伪标签可由自动化工具以极低放射科医生成本生成。

EdgeLM: Edge Demonstrations for Language Models' Table Understanding（EdgeLM：面向语言模型表格理解的边缘示例）

核心观点：大型语言模型（LLMs）通过上下文学习执行以表格为中心的预测任务，因此示例选择对性能至关重要。现有检索方法优先考虑与查询的相似性，但相似的示例往往强化模型已有的预测倾向，而非揭示困难决策所需的区分信息。我们提出EdgeLM，一种检索框架，转而选择“边缘证据”——既与查询相关、又对决策边界具有信息量的示例。EdgeLM通过两类互补的边缘证据进行检索：数据边缘（与目标邻近但真实标签不同的示例）和模型边缘（部署模型此前错误分类的相似示例）。该方法无需模型重新训练，也无需任务特定的工程调整。

主要贡献与结果：在5个数据清洗任务、15个数据集和5种开源及专有LLM上，EdgeLM在所有设置中均取得最佳或接近最佳的性能；消融实验表明，两类边缘证据提供互补增益。代码和数据集已公开于 https://github.com/soroushomidvar/EdgeLM。

Global Attention-Fused Image Cropping with Attention-Guided and Global-Aligned Crop Evaluator（基于注意力引导与全局对齐裁剪评估器的全局注意力融合图像裁剪）

核心问题：现有图像裁剪方法主要关注显著区域，对图像主要组成部分间的全局关系敏感度不足。

提出方法：提出GAFIC框架，包含两个关键模块：

1. Attention-Guided Feature Fusion（AGFF，注意力引导特征融合）：聚合局部区域重要性，构建同时捕捉图像结构与局部细节的全局表征。

2. Global-Aligned Crop Evaluator（GACE，全局对齐裁剪评估器）：将候选裁剪特征与全局表征对齐，使裁剪评估对边界变化保持敏感。

技术细节：结合三种多尺度排序损失，获得准确且稳定的裁剪分数。

主要结果：在GAIC和CPC数据集上的大量实验表明，GAFIC在准确性和稳定性方面优于现有图像裁剪方法。

方法特点：与像素级重定向方法（如seam carving、修复、扩散合成）不同，GAFIC不合成或修改保留像素，而是从源图像中选择美学上更优的裁剪区域，适用于需要像素完整性和高效批处理的场景。

代码开源：https://github.com/AIVRC/GAFIC.git

Rethinking Reservoir Pruning: A Dynamical Perspective for Echo State Networks（重新思考储层剪枝：回声状态网络的动力学视角）

核心观点：本文针对回声状态网络（ESN）中随机初始化储层存在过度参数化和动态冗余的问题，提出了一种基于动力学视角的储层剪枝方法。

方法创新：现有的剪枝方法多依赖静态连接性或激活统计，忽略了塑造输入驱动状态转换的神经元。作者提出动态模式剪枝（DMP）方法，通过轨迹平均雅可比Gramian矩阵获得主导转移模式，根据神经元对主导模式的贡献进行排序，移除低影响单元并仅重新训练输出层。

实验结果：在混沌时间序列和真实世界时间序列基准上的实验表明，DMP在减少冗余储层组件的同时，能够提高或保持预测精度。

主要结论：动力学影响力是超越静态结构重要性的储层优化有效准则。

What Is a Skill Worth? Structure-Aware Shapley Valuation of Agent Skills（技能价值几何？结构感知的智能体技能Shapley估值）

核心问题：智能体技能在自动化反馈回路中不断优化，产生结构化的长工件，但其内部单元（如规则、示例、脚本、启发式策略）的价值尚不明确。本文研究在固定智能体和保留任务分布下，对技能内部单元进行信用分配的技能估值问题。

与现有工作的区别：技能估值不同于数据或提示跨度估值，因为技能单元是结构化的——它们可能依赖其他单元、属于文档层级、触发智能体行为，并消耗有限的提示上下文。

方法创新（SkillSV）：提出一种结构感知的Shapley风格估值框架。该框架将技能编译为单元、依赖关系和层级结构，确保仅评估有效的反事实技能；采用配对删除和长度中性填充来区分内容价值与上下文成本；并使用基于 rollout 预算的估计器处理噪声智能体评估。

Differential 6-DOF Pose Estimation with Provable First-Order Immunity to Camera Calibration Errors（具有可证明一阶抗相机标定误差的差分6自由度位姿估计）

核心贡献：提出一种差分6自由度（6-DOF）位姿估计方法，直接通过帧间图像位移和已知3D控制点恢复平台运动，无需独立估计绝对相机位姿，从而避免外参标定误差的影响。

方法创新：通过对透视投影方程做差分、采用深度不变近似并在SE(3)上建模运动，方法无需独立的绝对位姿估计，同时支持单目和多相机系统。

理论保证：证明平移外参误差可完全抵消，旋转误差仅带来有界扰动（由标定误差、运动幅度和观测几何决定）；推导了可观测性条件、Cramér-Rao下界及无偏一致性估计器，并刻画了近似有效范围。

性能验证：在合成和真实数据上取得当前最优结果，在精度、标定鲁棒性和计算效率上优于代表性PnP和广义PnP方法。

实验数据：5个控制点+0.5像素图像噪声下，单目求解器：旋转RMSE 10.09角秒，平移RMSE 3.70 mm，运行时间0.34 ms；双目求解器：旋转RMSE 10.58角秒，平移RMSE 3.91 mm，运行时间0.27 ms。

应用场景：机器人操作、自主系统、结构位移监测等需要高精度6自由度微运动估计的场景。

InsightEmb: Learning Action-Intent Embeddings for Agentic Insight Retrieval（InsightEmb：学习用于代理智能体洞察检索的动作意图嵌入）

核心问题：自我改进的智能体会从先前轨迹中积累可复用的洞察，但现有检索方法仅建模语义相似性，忽略了检索到的洞察能否解决智能体当前面临的决策瓶颈。作者将此设定称为“代理智能体洞察检索”（agentic insight retrieval）。

方法创新：提出InsightEmb——一个对比嵌入框架，仅使用数学推理数据即可学习可迁移的、面向进展的检索几何结构。该框架联合学习两点：1）将具体情境与抽象启发式规则对齐；2）将具有相似进展结构的推理轨迹聚类。

评估结果：在动态智能体任务和静态技能检索基准上，InsightEmb无需任何环境特定训练，在所有评估中均超过现有推理嵌入模型。

核心结论：状态-洞察匹配的几何结构可以跨领域迁移，使得仅使用公开推理数据即可进行有效训练，无需昂贵的环境特定监督。
