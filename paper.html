HaReCAP: Habitual-action Grounding for Recursive Large Language Model Agents（HaReCAP：递归大语言模型代理的习惯性动作锚定）

长时程具身任务要求LLM代理迭代式地分解高层目标、根据环境反馈修订计划，并将叶级子目标落地为可执行动作。现有的递归上下文管理方法（如ReCAP）通过多级任务分解与父节点修正提升了规划稳定性，但在叶节点仍会反复调用LLM将原子子任务锚定为精确有效动作——这一最终锚定步骤被定义为“最后一英里锚定冗余”，在长时程执行中累积为大量LLM调用与token开销。为缓解该问题，本文提出HaReCAP（习惯性动作锚定的ReCAP），一种面向ReCAP的低侵入式叶节点锚定扩展。其核心思路为：从成功轨迹中提取高频叶级决策，离线编译为可审计、可弃权的一步式叶级反射规则；运行时，仅当规则能在当前有效动作集合中唯一确定合法动作时才跳过叶节点LLM调用，否则回退至原始ReCAP流程。该设计避免了将完整递归上下文反复带入LLM处理常规叶级动作锚定，同时保留了原始递归控制流。在Robotouille与ALFWorld上以Qwen3.5-27B为主模型评估：在ReCAP与HaReCAP均能解决的任务中，HaReCAP在Robotouille同步、Robotouille异步、ALFWorld上分别降低token消耗14.67%、17.93%和20.08%。结果表明，HaReCAP可作为ReCAP类递归上下文管理框架的低侵入扩展，在常见成功轨迹上跨环境与模型减少最后一英里锚定冗余。

方法（HAF框架）：提出由HAF-VLA与HAF-Steer两部分组成的适配框架，将现成通用VLA迁移至人形全身移动操作。HAF-VLA为分层动作流生成器，基于预训练的流匹配VLA，将全身动作去噪分解为三个顺序阶段，通过阶段嵌入与跨阶段KV缓存保留运动学依赖，避免一次生成导致的不连贯全身动作。HAF-Steer为潜在空间离线到在线强化学习管线，利用流匹配可逆性与DCT降维将RL优化限制在紧凑噪声子空间，训练正则化SAC策略，无需更新VLA骨干网络即可实现高效真实世界策略优化。

结果：在七个真实世界人形移动操作任务上，HAF超越单阶段VLA基线，显著提升全身协调性与任务完成度。

Nexus: Structured Synergy for Efficient Text-to-Image Generation using Rectified Flow Model（Nexus：基于修正流模型的高效文本到图像生成的结构化协同）

Spatial Temporal Synergy: Balancing Change and Invariance in Text Driven 3D Human Motion Editing（时空协同：文本驱动3D人体运动编辑中变化与不变性的平衡）

核心问题：文本驱动的3D人体运动编辑旨在根据自然语言指令修改现有动作序列，同时保持原始运动的结构一致性。现有基于扩散模型的方法难以平衡文本响应的“变化”与运动固有的“不变性”，常因粗粒度空间约束和刚性统一时间假设，导致空间运动畸变及变长编辑中内在物理节奏的破坏。

方法创新：作者提出变化与不变运动编辑框架（CIME），将变化与不变性在空间姿态和时间节奏两个维度上彻底解耦：1）空间姿态维度：引入全监督正负学习机制，包含层级回顾特征监督、细微运动保持和三元组语义对齐；2）时间节奏维度：提出黎曼非均匀积分流形映射模块（RNIMM），通过运动学感知的非均匀时间戳实现编辑文本中物理节拍的高保真复现。

实验结果：在MotionFix与STANCE Adjustment数据集上的广泛实验表明，CIME在编辑对齐和结构保真度方面均达到最优性能，验证了统一架构的有效性。代码与模型已开源：github.com/ZhenwuShi/CIME.git

Towards Zero-Shot Domain Generalization for ID Cards Presentation Attack Detection（面向身份证呈现攻击检测的零样本域泛化研究）

核心问题：身份证呈现攻击检测（PAD）因缺乏公开的真实样本而受限，导致系统难以跨国家/地区泛化。

PixRestore: Unified Image Restoration via Pixel Diffusion Transformer（PixRestore：基于像素扩散Transformer的统一图像恢复）

核心问题：统一图像恢复（UIR）旨在用单一模型从不同退化类型的低质量（LQ）图像中恢复高质量（HQ）内容。现有方法多依赖预训练文本到图像（T2I）潜空间扩散模型，但存在两大缺陷：变分自编码器（VAE）会丢弃恢复敏感的细节；开放式的合成先验易引入内容不一致的伪影。

方法创新：提出PixRestore，一种无VAE的像素空间扩散Transformer（DiT）用于UIR。扩散主干完全从零训练，不依赖T2I预训练，直接在分块像素上进行流匹配，既保留细粒度细节又保持序列长度可控。为适应不同退化类型，利用LQ-HQ的DINO特征相似度预测各层特征的可靠性：可靠层的特征融合为密集条件，不可靠层则施加强HQ特征监督以促进退化去除。

训练与推理：在包含多样场景和退化的大规模语料上训练，并使用基于DINO的对抗目标进一步微调为单步生成器，实现高效推理。

主要结果：仅约5000万参数且单步推理，在公共基准和真实世界测试集上，相较于同类UIR模型取得最佳的整体保真度、感知质量和退化鲁棒性，同时效率远高。更大规模的PixRestore变体可进一步提升性能，证明像素空间设计的可扩展性。代码与基准已开源。

Steering the Flow: Inverting Face Recognition Models via Gradient-Guided Flow Matching（引导生成流：通过梯度引导的流匹配实现人脸识别模型反演）

核心要点总结：

1. 问题背景：模型反演攻击（MIAs）旨在从人脸识别模型中重建目标身份的代表性训练样本，暴露严重的安全漏洞。现有方法依赖间接或高度随机的引导，难以稳定地优化生成轨迹以逼近目标人脸图像。

2. 提出方法：本文提出引导流模型反演（SFMI），一种新颖的两阶段白盒模型反演方法，将反演重构为轨迹引导任务：
- 第一步：学习通用流匹配先验——预训练一个无条件流匹配模型，编码人脸流形作为稳健先验。
- 第二步：使用渐进式引导调度器（PGS）进行攻击——在采样过程中注入随时间变化的目标特定梯度，通过反向传播目标模型获取中间生成状态的梯度，逐步将自适应引导信号注入向量场，有效将当前生成流从随机噪声引导至目标类别的高密度区域。

3. 实验结果：在CelebA数据集上的身份不相交交叉评估设置下，SFMI在ArcFace目标上达到ACC 0.9248、FID 22.61、LPIPS 0.3874。多个目标模型上的大量实验表明，在被评估的白盒协议下，SFMI在攻击成功率和视觉保真度方面均达到具有竞争力的最先进性能。

IndicQE-APE: A Benchmark for Quality Estimation and Automatic Post-Editing for Indic Languages（IndicQE-APE：面向印度语言的译文质量评估与自动译后编辑基准）

印度语言的质量评估（QE）和自动译后编辑（APE）数据分散在不同发布版本中，缺乏一个统一的资源来支持跨任务、跨语言对的训练与评估。本文整合了WMT 2020–2024共享任务系列，并扩展了英语–马拉雅拉姆语资源，构建了IndicQE基准：涵盖9个方向性语言对，共126,754个实例，每个片段对齐最多四种标注类型（直接评估、人工译后编辑、词级OK/BAD标签、错误解释），测试集按四个难度轴分层。基于该基准，本文评估了六个提示式大语言模型（LLM）和三个COMET指标在片段级QE上的表现，以及三个系统在APE上的表现。四个难度轴中有两个部分依据直接评估定义并压缩其切片，因此每个轴均与来自同一语言对、分数分布相同的对照组对比，结果仅一个轴在控制下显著：整体质量信号与词级质量信号冲突的片段，其排名低于同一语言得分相同的片段，该结论在所有九个系统和承载该轴的七个语言对上一致成立。标注者分歧在无控制时看似第二难，但在控制后无影响。少样本提示使所有≤3.4B参数的模型在相关性和输出格式合规性上均有下降。语言内准确性无法使分数跨语言对可比：三个训练指标中，语言内相关性最好的指标在合并语言对后损失最大。基准和代码将公开发布。

Neurosymbolic Embodied Agents（神经符号具身智能体）

核心问题：语言和视觉语言模型能生成看似合理的具身任务计划，但无法保证可执行性——其输出可能违反环境动态规则，或错误作用于不正确的实体上。

方法：提出一种神经符号智能体，将长周期家务任务分解为任务导向的视觉探索与受限符号规划两个阶段：

1. 第一阶段：视觉语言模型与探索工具从第一视角观察和基于交互的数据中获取目标相关的谓词和实例绑定，构建符号化的初始状态。

2. 第二阶段：PDDL转移模型将解码限制为只生成可执行动作对应的token；随后蒙特卡洛树搜索利用领域无关的规划启发式评估可执行的后续行动。

由此生成的计划在转移模型下保证可执行性，且仅需正确的视觉基础即可迁移至真实环境。

主要结果：

• 在VirtualHome和ALFWorld环境中，开源4B-27B模型在两个环境中成功率均超过90%；最小规模的智能体也大幅优于27B直接视觉策略。

• 约束与搜索互补而非可互换：在ALFWorld中，二者单独使用仅能解决不到三分之一的任题，组合使用则可解决超过95%的任务。

• 相比于扩展推理方法，该方法生成token数量减少数倍；所需模型可见图像远少于直接交互方法。

• 残余失败主要归因于状态获取阶段，而非计划生成阶段，且无需任何专门训练。

Pallas: A Proactive KV Cache Migration Framework for LLM Inference in AI-RAN（Pallas：AI-RAN中面向LLM推理的主动式KV缓存迁移框架）

AI-RAN将大语言模型（LLM）服务部署到移动用户附近，但蜂窝切换可能导致活动请求与其推理状态分离：用户连接到目标基站（gNB），而不断增长的关键值（KV）缓存仍留在源端。在源端保留推理可维持服务连续性，但会持续增加令牌间延迟（ITL）；而在目标端恢复状态可恢复服务本地性，但需要在切换后执行KV缓存传输、重计算或两者结合，这直接延长了服务中断时间（SIT）。

本文提出Pallas，一种主动式KV缓存迁移框架，在切换前就在预测的目标端准备推理状态，与源端正在进行的推理和令牌传输并行进行。在准备触发时，Pallas将令牌序列划分为稳定的历史前缀和动态演化的后缀。目标端通过本地预填充重建前缀，而源端流式传输为后缀生成的KV块。切换时，目标端将两部分组装成最新的KV缓存并恢复本地解码，仅将未完成的准备工作计入SIT。在线调度器基于移动性预测和运行时遥测选择预取窗口，该窗口决定切换前准备开始的时间。在三种LLM和100–500 Mbps的gNB间链路上，基于vLLM的原型相比目标端恢复方法将平均SIT降低了2.28–89.68倍，相比源端转发将平均ITL降低了16.0%–50.0%。

TransAnyText: Translating Arbitrary Text in E-commerce Images via Structured Visual Generation（TransAnyText：通过结构化视觉生成实现电商图像中任意文本的翻译）

核心问题：跨境电商图像翻译（如商品图、横幅、详情页）需同时满足翻译准确、视觉身份保真、输出易编辑三大要求，现有方法难以兼顾。

创新方法：提出TransAnyText框架，将图像文本翻译重构为“从源图像+目标语言生成可渲染的HTML代码块”。核心是解耦语义生成与像素渲染：视觉语言模型（VLM）负责视觉理解、跨语言翻译和结构化代码生成；扩散模型负责背景修复与像素级精修；最后通过确定性渲染合成最终图像。

训练策略：采用三阶段后训练框架：①监督微调（SFT）建立“图像-代码”映射；②特权差距加权自蒸馏（PWSD）提升风格与布局令牌的学习；③基于可验证奖励的强化学习（RLVR）进一步优化任务级性能。

数据与评测：构建了TransAnyDataset（多语言数据集）和TransAnyBench（电商图像翻译基准）。

实验结果：相比级联流水线、开源端到端模型及闭源图像编辑系统，该方法在性能上具有竞争力，为跨境电商图像翻译提供了有效、可控、可编辑的解决方案。

Representation Is Not Enough: Body-Localized Thermal Evidence for Contactless Stress and Craving Sensing in Opioid Use Disorder（表征是不够的：用于阿片类药物使用障碍中无接触式压力与渴求感检测的身体局部热学证据）

实验结果：在受控合成实验（维度256，秩32，语料库从3,000文档增长至9,000文档，经历50次更新）中：增量低秩更新每次更新成本仅为完整重新SVD的1/33.7，累计成本低至1/23.8；增量子空间追踪完整重算的精度达到浮点极限（最大主角度漂移低于1e-11度；recall@10 = 1.0）。采用正交Procrustes虚拟轴更新，仅重新嵌入约10%的语料库即可恢复0.95的平均余弦相似度，逼近真正重新嵌入的向量。

结论：研究结果支持对语义基底进行增量维护，而非反复重建。

Reconstruction: A Blind Benchmark for Recovering Research Ideas from Pre-Publication Bibliographies（重建：从预出版参考文献中恢复研究思路的盲测基准）

本文提出一个名为“Reconstruction”的全新盲测基准，旨在检验语言模型仅凭论文预出版时的参考文献，能否还原出该论文的真实研究思路。基准采用严格的防泄漏协议——包括时间引用截断、匿名引用编号以及冻结每篇论文的参考文献列表——从而避免模型在推理时接触到目标论文的核心思想。在六个科学领域、643篇已评估论文中，七个前沿模型仅取得约3%–15%的中等匹配率。此外，作者评估了一个仅基于参考文献的多智能体流水线（排名前4），该流水线融合了跨模型评审与基于对齐假设槽的瑞士锦标赛机制，且不依赖外部网络搜索。实验结果显示，跨模型评审加锦标赛选择可将匹配率提升至约23%–42%，相较最佳单模型基线实现了约2.4倍的显著提升。本稿作为arXiv时间戳，报告了该协议、防泄漏设计及当前实验结果。
