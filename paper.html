When Does Machine Learning Beat Value Sorting? A Three-Dataset Diagnostic of Exposure-Weighted Shipment Prioritization（机器学习何时优于价值排序？基于三个数据集的加权风险货运优先级诊断）

延迟风险模型通常以预测准确性评判，但实践中更关键的是：在只能审查少量货运的情况下，管理者应优先检查哪些？本文评估机器学习能否超越一个严苛的无模型基线——即优先检查最高价值货物。基于SCMS采购、DataCo物流和Olist电商三个真实供应链场景，采用泄漏控制的滚动起点评估和1000次配对自助法置信区间，通过预测延迟严重程度乘以已知价值进行排序（M1）在所有三个数据集中均优于仅按严重程度排序，但并未全面优于价值排序。在10%审查预算下，M1相对于纯价值排序（VALUE_ONLY）的差距为：SCMS -5.5个百分点，DataCo +10.1个百分点，Olist -4.9个百分点。这一差异与严重程度的可学习性一致：DataCo的R²=0.27且校准偏差为+0.01天，而SCMS和Olist的R²约为-0.02且校准偏差为负。嵌套交叉验证的成本敏感重训练未能在M1基础上带来稳定改进。本文并非提出新学习算法，而是提供了一个部署诊断和评估协议。价值排序应作为永久基线，仅在严重程度可学习性和校准通过审核，且模型在泄漏控制的滚动起点评估中通过该门槛后，才应部署机器学习。

SFGA: A Statistics-First Gating Architecture with Adjudicative Escalation for Trustworthy SFT Data Procurement（一种统计优先的门控架构，通过裁决升级实现可信的SFT数据采购）

本文提出SFGA，一种统计优先的门控架构，将SFT数据采购视为成本感知的路由问题，围绕多样性、效用和冗余三个核心质量维度进行决策。低成本盲测结果被汇总为各维度的区间估计；仅当区间紧凑、样本充足且各维度一致时，门控才接受决策，否则将案件升级至“购买-支持者”与“拒绝-支持者”法官之间的裁决辩论，由主审法官做出终裁。在12个数据集（三轴2×3×2格）的5次随机种子的受控基准测试中，该门控每单元成本0.017美元，达到了0.90准确率和0.83的F1值，介于始终验证基线（0.75）与理想上界（0.98）之间，且成本低于始终升级方案（0.020美元）。论文还报告了辩论路径的诚实负面诊断：反方胜率为0.80（p≈3×10⁻⁶），且在立场互换下52%的立场翻转率揭示了朴素LLM法官会隐藏的消极性和位置偏见。论文明确将注入旋钮评估作为测量保真度和路由校准的受控合成基准，并将外部有效性界定为未来工作。

The Shared Discovery Paradox: How a One-Answer Rule Turns Better Information into Worse Search（共享发现悖论：单一答案规则如何将更好的信息转化为更差的搜索）

组织常将分散信息汇总为一个排名，让多个主体基于该共享观点行动。在发现任务中，这能提升信念但会降低覆盖范围。我们构建了一个可精确求解的基准模型（16个盒子、1个目标、8名搜索者、含噪声私人线索）。汇总使最佳单一推荐的准确率从0.20提升至0.3835，但重复该推荐导致群体发现率从分散线索追踪下的0.8322降至0.3835。基于相同汇总报告的协调八行动组合可达到0.8594，七个协调行动即可恢复分散基准水平。悖论本质是协议失效而非信息失效：单一答案规则将可用行动组合压缩为单一重复选择。当用追逐奖赏的自利搜索者替代规划者时，等分博弈属于势博弈，其匿名对称均衡遵循注水规则，在标准实例中达到0.5991——严格高于共识但低于私人搜索和规划者水平，精确混合价格无政府状态为2 - 1/N。仅奖励独自覆盖目标的独救报酬机制能使所有纯纳什均衡达到最优。最后，潜在公共线索模型显示关联报告会压缩有效发现渠道：集中规划者的收益随复制严格递增，在标准环境中当复制概率c=0.788462时对称市场超越分散报告追踪。在比例化大市场极限下，五种协议排序严格保持——共识发现消失，而盲目、市场、私人、组合搜索分别收敛至0.500、0.547、0.847、0.874。本文贡献在于提供一个将信息、分配、激励与依赖关系分解为精确可复用量的紧凑基准模型。

FLINT: Fingerprinting Federated Learning Architectures from 5G PHY-Layer Side Channels（FLINT：通过5G物理层侧信道识别联邦学习架构）

联邦学习（FL）在5G蜂窝网络中保护原始数据，但仍易受侧信道泄漏攻击。以往的指纹攻击假设具备数据包级网络可见性，但这一假设在5G物理层（PHY）不成立，因为用户有效载荷被加密，且无线网络临时标识符（RNTI）会随时间变化。然而，我们证明在物理下行控制信道（PDCCH）上广播的物理层调度元数据保留了与架构相关的时间模式。我们提出FLINT，一种新型黑盒指纹识别框架，仅使用粗粒度的物理层观测就能推断FL模型架构族，包括CNN、RNN和Transformer。FLINT通过解码PDCCH调度信息、将变化的RNTI映射到物理用户设备，并应用多视图时间建模来区分特定架构的训练行为，从而克服了缺乏网络层可见性的问题。这种泄漏具有安全关键性，因为了解客户端的模型架构可以将被动侦察转化为有针对性的下游利用。在基于srsRAN的空中5G测试平台上进行的广泛实验表明，FLINT在架构族分类上达到了0.930的宏F1分数。据我们所知，FLINT是首个利用任何协议感知攻击者都能获取的低层5G侧信道信息来识别AI/ML模型架构的工作。

How Rules Represent Causal Knowledge: Causal Modeling with Probabilistic Logic Programming（规则如何表征因果知识：基于概率逻辑编程的因果建模）

Pearl著名地论证了因果知识能够预测干预效果，而纯描述性知识仅支持基于观察的结论。然而，他的因果理论仅在贝叶斯网络和因果模型内发展，因此主要局限于无环因果关系，将其思想迁移到其他形式主义中可能导致误解或不一致。本文将Pearl的因果方法引入概率逻辑编程（PLP）。为此，这些程序与先前工作中建立的不依赖时间概念的哲学基础保持一致，即所有相关事件均假设同时发生。本文提出了针对这些程序的形式化因果语义，以及干预概念和实现方法。结果表明，该语义与分层ProbLog程序的P-log语义一致，但在非分层情况及其他PLP形式主义中可能有所不同。

Achieving Text-based Person Retrieval with Any Granularity（实现任意粒度的文本行人检索）

文本行人检索面临一个关键但尚未充分探索的挑战：现实场景中查询粒度的固有不确定性。本文提出了一种新范式——任意粒度文本行人检索，并提供了系统性解决方案。首先，我们形式化了一个五级粒度谱，并通过新颖的多粒度文本标注引擎，构建了高质量的多粒度数据集UFine6926-MG，在所有粒度上进行了全面标注。其次，考虑到粗粒度查询自然对应多个有效候选，我们提出了MG-Eval评估基准，包含逐步精细的文本和反映真实语义的跨身份标签，以及定制化评估指标与协议。第三，在全面诊断揭示现有研究系统性局限后，我们提出了跨模态多粒度对齐与匹配（CMAM）框架。CMAM通过以下方式实现粒度感知检索：1）正交专家感知以解耦粒度特定特征；2）概率对齐以建模查询不确定性下的多对多匹配；3）粒度一致推理，通过联合跨模态粒度验证引导特征学习。实验表明，CMAM在所有粒度级别上均显著优于现有最优方法。本研究建立了基础基准与稳健基线，为更实用的行人检索系统铺平了道路。

Exposure is Optional: Learning Unlike Coordination in Language Models（暴露是可选的：语言模型中异类并列的学习）

本文探讨语言模型是否必须通过直接暴露于训练数据中的“异类并列”结构才能习得其处理能力，抑或这种能力能从一般的组合性能力中自然涌现。通过使用滤除所有异类并列实例的语料库训练GPT-2模型（过滤语料训练法FiCT），研究发现直接暴露并非必要：经滤波数据训练的模型成功泛化至异类并列，其困惑度和语法判断表现与在未滤波文本上训练的模型相当。内部表征分析进一步表明，语言模型处理异类并列时，要么将并列元素视为归属相似结构类别，要么通过类似删除的机制进行处理——这两种机制均可从仅接触“同类并列”的过程中习得。该工作推进了对语言模型内部表征语言结构的理解，同时通过揭示模型无需直接暴露即可泛化并处理异类并列的现象，为关于并列结构的更广泛争论提供了新视角。

PerceptDrive: Perception Prior World-Action Modeling with Adaptive Expert Routing for End-to-End Autonomous Driving（感知优先的世界-动作建模与自适应专家路由用于端到端自动驾驶）

针对预训练感知模型因静态融合而忽视任务线索、无法适应不同场景的问题，提出PerceptDrive框架。该框架通过教师蒸馏的先验与冻结视频编码器的密集观测，输入可训练的专家路由世界-动作模型。专家分支处理信号，并用先验保留目标锚定各分支；路由器从共享场景表征预测软门控，组合专家条件。训练时利用基于规则的子指标进行软门控蒸馏；推理时仅需一个前置摄像头，无测试时评分或搜索即可生成轨迹。实验表明，PerceptDrive在NAVSIM v1上达到90.4 PDMS、在NAVSIM v2上达到90.2 EPDMS，性能超越现有方法。消融实验证实，保留并自适应路由感知先验可提升直接规划能力，且三个先验的依赖具有差异性。

RIM: A Retrieval-In-Matching Framework for Cross-Domain Global Visual Localization of UAVs（RIM：面向无人机跨域全局视觉定位的检索匹配框架）

针对无人机（UAV）利用遥感参考地图进行全局视觉定位时，因获取时间与成像平台差异导致的跨域外观和视角变化问题，本文提出一种高效解决方案。通过从Google 3D瓦片采样多位置、高度和方向的无人机视角参考视图，结合两阶段跨域微调策略（利用近正样本和地理远难负样本优化SALAD模型，并基于局部几何一致性对Top-K候选进行重排序），进一步提出了检索匹配框架（RIM）。该框架冻结经适配的DINOv2-B检索器，蒸馏出局部描述子解码器以复用其标记场，并引入浅层VGG19细节流，使单次查询侧DINOv2-B前向传播同时服务于SALAD检索与局部描述，无需额外基础模型骨干，同时保留检索表征。在训练数据地理分离的EPFL Urbanscape和自采长安公园数据集上的零样本评估中，RIM优于十种最新检索基线。在全3D距离指标下，25/50米区间内，RIM在EPFL上比SALAD的Recall@1分别提升8.55/13.77个百分点，在公园数据集上提升4.45/8.94个百分点。在Top-K=5时，完整测量定位查询（含检索、候选匹配及稳健几何验证）端到端耗时67.9毫秒，速度分别为最强独立稀疏匹配基线的1.8倍和RoMa的40倍以上，且重排序精度相当。该成果为GNSS受限环境下的无人机全局视觉定位提供了高效、可部署的流水线。

Agentic Context Management: Solving Agent Memory and Cost by Treating Them as Lifecycle and Architecture Problems（智能体上下文管理：将智能体记忆与成本问题视为生命周期与架构问题）

生产环境中的AI智能体失败，通常并非推理能力不足，而是无法有效管理其推理上下文中的内容（如对话历史、大型提示、工具定义及持续膨胀的工具输出）。智能体会被自身累积的历史淹没，每轮对话的token成本不断增长，并导致对话内外的信息遗漏。现有解决方案将此视为存储与检索问题，但本文认为这一框架过于狭隘。主动管理智能体“记住”的内容本质上是生命周期管理，而非单纯存储：它涵盖决定记忆内容、提取并结构化信息、按数据类型选择存储方式、保留来源的同时进行合并与遗忘、判断当前相关性、预测下一步需求，以及将上下文压缩至预算范围内且不丢失关键信息。在严肃的生产场景中，这一过程需跨越单个用户，在组织范围的层级结构中运作。我们将其命名为“智能体上下文管理”（Agentic Context Management, ACM），并分解为五个基本操作：架构设计（Architecting）、摄取（Ingesting）、范围界定（Scoping）、预判（Anticipating）以及压缩与合并（Compacting & Consolidation）。从经济性来看：原生上下文累积会导致token成本随对话长度呈二次方增长；简单摘要虽能将成本降至线性，但会引发准确性断崖式下降；只有经过验证的压缩（Validated Compaction）才能以线性成本保持信息保真度。我们描述了参考实现Maximem Synap，它将五个基本操作为多租户服务，在特定配置下于LongMemEval和LoCoMo上分别达到92%和93.2%的准确率。最后，我们指出了现有基准未能覆盖的维度（延迟、token效率及上下文抗腐烂能力），以及该方向在决策级和组织级上下文管理方面的前沿探索。

OpenRTAG: A Comprehensive Benchmark for Robust Text-Attributed Graph Learning under Data Quality Degradation（OpenRTAG：数据质量退化下鲁棒文本属性图学习的综合基准）

文本属性图（TAGs）是结合关系结构与丰富节点文本的重要图数据形式，但真实世界中的TAG常因文本、结构和标签问题而存在质量缺陷，主要表现为稀疏、噪声和不平衡。这三个维度定义了九种典型退化场景，严重影响TAG学习。此前研究虽探索了特定缓解策略，但证据分散在退化类型、数据集、任务和模型家族中，对TAG鲁棒性的理解尚不充分。为此，我们提出OpenRTAG，一个面向文本属性图学习的鲁棒性基准。OpenRTAG将TAG质量问题组织为统一的3×3分类体系，支持对九个TAG数据集和三个下游任务进行标准化评估。它系统评估场景有效性和模型敏感性，比较传统GNN、LLM-GNN及代表性GFM，考察场景匹配基线的有效性、效率和鲁棒性，并进一步研究复合退化场景下的模型行为。OpenRTAG为理解低质量现实环境下TAG学习的鲁棒性提供了标准化测试平台。

Sparse Evidence Can Suffice: Agentic Evidence Seeking for Multimodal Video Misinformation Detection（稀疏证据足以胜任：面向多模态视频虚假信息检测的智能体证据搜寻）

多模态视频虚假信息检测通常被当作整体视频理解任务，即一次性处理并判断整个视频及其关联内容。然而，真实世界的虚假信息往往具有稀疏且组合的证据结构：可靠的决定可能仅依赖少数几个耦合线索，而大部分视频内容提供的附加信息有限。全面的多模态推理因此可能引入大量冗余，并掩盖决定性证据。这促使我们将证据获取与验证分离：首先识别稀疏、与决策相关的线索，然后基于获取的证据判断真实性。据此，我们提出了SIEVE框架，即通过提取进行稀疏交互式证据验证。一个证据搜寻智能体主动探索可用的多模态证据，构建紧凑的证据包，随后由验证器据此判断真实性。该智能体通过有监督的证据搜寻轨迹和一种证据感知的强化学习目标进行训练，该目标鼓励获取信息性证据，同时抑制不必要或无效的交互。在多个视频虚假信息基准测试上的实验表明，SIEVE持续优于评估的基线方法，并能使用紧凑证据包支持可靠的验证。此外，其证据获取过程提供了明确且可检查的证据轨迹，提高了多模态虚假信息检测的透明度和基于证据的可靠性。

Webly Supervised Multi-Label Recognition: Evaluation Benchmark and Dual-Branch Multi-Label Contrastive Learning（网络监督多标签识别：评估基准与双分支多标签对比学习）

利用网络图像训练深度学习模型可减少对昂贵人工标注的依赖。尽管网络监督学习在单标签识别中已被广泛研究，但其多标签识别任务仍未被充分探索，部分原因在于缺乏统一基准和公平比较协议。为填补这一空白，我们构建了网络监督多标签识别（WS-MLR）基准，包含Web-COCO和Web-Pascal两个数据集，并在统一设置下重新实现了代表性基线方法。这两个数据集分别涵盖与MS-COCO和Pascal VOC相同的80个和20个类别，包含约30万张通过类别关键词组合从互联网检索的图像。我们进一步提出了双分支多标签对比学习（DBMLCL）框架，该框架联合学习类别特定的实例级与类别级表征及其相似性，以识别和校正噪声标签。在基准上的大量实验表明，DBMLCL相比代表性基线方法取得了更优越的性能。

DINOde: Continuous Vision-Text Alignment for Open-Vocabulary Semantic Segmentation（DINOde：面向开放词汇语义分割的连续视觉-文本对齐）

Equilibrium Causal Games: Separation, Identification, and the Identifiability of Cyclic Latent States（均衡因果博弈：分离、识别与循环潜状态的可识别性）

电网、市场及交互群体通过未知传感器观测到的反馈驱动均衡中稳定下来。本文提出的均衡因果博弈（ECG）将博弈与其循环因果模型、隐藏输入、传感器映射以及干预和均衡选择规则相结合；干预修改声明的对象并重新计算均衡。在给定条件下，ECG分离在我们的示例中虽是可靠的，但不完备。后门/半途路径可识别观测查询。然而，对于未触及的旋转对称高斯块，二阶矩仅能确定一个源帧旋转，在此旋转上不同变量效应通常会发生改变。未知感知会产生另一个歧义。在无自效应的被动稳定线性模型中，未知布线与满秩未知感知使得当$d\ge2$时$B$完全无法识别。在LiNG下，非高斯性消除了源旋转；机制干预将感知与交互分离开来。在未知支持、不变感知、对齐响应及适定单目标干预下，$(H,B)$可被识别至声明的等价性。在$d$个目标中，当且仅当唯一未瞄准的节点是所有其他节点的直接父节点时，$d-1$个目标恰好足够；否则需要$d$个。采集探针被排除；已知布线不提供通用计数。对于非线性感知，各向同性高斯源块在标记环境中允许块内和块间的隐藏扭转，这些环境保留了所需的径向规律。相反，在所述正性、信息性单块变化、秩及不可约性条件下，最精细的独立源块表示可在声明的替代类中被识别至块排列和块坐标变化，但不能识别下游机制或传感器/交互分割。综上所述，这些结果表明哪些因果结论可由均衡数据支持，哪些需要定向实验。

FlowBlock: Wavefront-Parallel Decoding for Self-Correcting Diffusion Language Models（自校正扩散语言模型的波前并行解码）

本文研究多环境因子模型：从异质环境收集高维协变量，部分环境提供辅助标签。协变量的联合分布随环境变化，而潜在结构被分解为共享载荷的不变因子和环境特异性载荷的异质因子。该模型受迁移学习和潜在因子回归启发，旨在为解释和稳健的样本外预测响应Y提取稳定低维表示。利用不变性原理，我们证明在最小结构条件下，不变因子与异质因子可被解耦。基于此，提出ATLAS（通过潜在对齐实现跨异质环境的辅助标签与不变性引导迁移），该统一流程利用不变性原理分离对齐的不变因子与未对齐的异质因子，并进一步借助辅助标签监督从异质因子中提取预测不变且可迁移的因子。ATLAS在下游潜在因子回归中实现近乎最优性能，在辅助标签可用时通过完整潜在信号在新环境中进行可迁移预测，否则退化为仅基于不变因子的稳健预测。我们建立了恢复不变因子与异质因子、识别所有响应不变因子及估计Y中不变信号的尖锐非渐近误差界。

Forecasting the Number of Harvest-ready Fruits of Sweet Peppers Using Multimodal Time-Series Data（利用多模态时间序列数据预测甜椒可收获果实数量）

核心摘要：针对个体植株级别的精准产量预测需求以及现有数据集的不足，本文贡献了一个新的带注释图像时间序列数据集（覆盖691株甜椒，4837张图像，并按成熟度分类果实数量）。研究提出了一个多模态深度学习框架，通过结合DinoV3图像编码器和LSTM网络，融合高维图像特征与数值计数，从而建模时间依赖性和处理不规则采样间隔。实验证明，该多模态方法在2022和2023季相比基线降低了33%和38%的RMSE，且相比仅使用测量数据的模型平均再提升1.2%。此外，通过深度集成和高斯负对数似然提供校准的不确定性估计（UCE在0.39至0.89之间），为农业决策提供可靠的置信信号。数据集和代码已开源。

Toward Optimal Adenovirus Detection Using YOLO26（使用YOLO26实现腺病毒最优检测）

本研究系统性地比较了YOLO26不同模型规模下的多种数据增强配置，以确定腺病毒在透射电子显微镜（TEM）图像中最有效的检测方案。被比较的配置包括NAS、GAS、GMAS和DAS，均在相同训练条件下进行评估。腺病毒数据集选自已发表的TEM病毒数据集，通过利用腺病毒颗粒位置重新标注，生成YOLO兼容的边界框标注。实验结果表明了所比较的数据增强配置对YOLO26检测腺病毒的影响，并指出了最有效的数据增强配置。

QuantiBias: Benchmarking Quantization-Induced Bias in LLMs（量化偏差基准测试：大语言模型量化引发的偏差）

几乎所有面向广泛受众的大语言模型都会经过量化处理：先以全精度训练，再为提升效率而压缩。这一步骤通常被认为无害，其安全性极少被重新核查。本研究发现，量化最主要副作用是增加了标准安全评估未能检测到的偏差。在固定模型、训练数据和提示的情况下，量化模型仍会拒绝有害请求，仍能避免过度拒绝良性提示，并继续选择无偏见的单项选择题答案。然而，当提出开放式问题时，同样的模型在我们探测的全部八种语言中都会主动输出刻板印象，在独立裁判评估下，约四分之一（跨越不同压缩级别的回答中，出现率约为24%至27%）的开放式回答带有刻板印象：它通过了所有标准检查，但用户接触到的模型却明显更具偏见。这种选择性差距是一个稳健的发现；而开放式偏差是否会随着压缩程度进一步提高，则不太确定，且对裁判评分标准敏感。为此，我们提出了QuantiBias基准测试，它结合了生成式多语言刻板印象探查工具、用于隔离开放式生成的拒绝与多项选择控制实验、对比是否加入推理步骤的构建方式，并对其生成内容的严重性进行评级。在两个主干模型（Qwen 和 Gemma）、五个家族筛选和八个基准测试中，量化器根据不含偏见预防信号的能力数据来分配其额外精度；推理后再回答大致可将某些家族的偏差效果减半，但对其他家族则毫无作用。量化后的模型必须针对开放式偏差进行重新评估，而不能仅依据它已通过的简短形式的安全保障机制。
