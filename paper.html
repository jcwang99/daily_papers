Perspectives on Tsallis Statistics for Artificial Intelligence（Tsallis统计在人工智能中的观点）

摘要总结：

Tsallis统计通过一个实参数 $q$ 推广了Boltzmann-Gibbs统计力学，该参数控制对稀有与频繁事件的权重分配。其最初用于描述具有长程关联、多重分形几何和重尾涨落的物理系统，现已成为现代人工智能中的常用工具，支撑了稀疏注意力机制（如Sparsemax和α-entmax）、具有可控探索的最大熵强化学习、稳健的重尾概率模型，以及一系列广义损失函数和正则化器。

本文系统地梳理了Tsallis统计与AI的交汇点。首先回顾其数学核心：$q$-熵及其变分（最大熵）基础、$q$-指数与$q$-对数、$q$-中心极限定理、$q$-高斯分布及其在超统计中的动力学起源，重点关注对机器学习重要的性质。随后综述了在softmax推广、强化学习、序列与图神经模型、生成与概率建模、损失设计及优化中的应用，并提炼出每种情况下的共性设计模式：由 $q$ 控制的密集/均匀与稀疏/尖峰行为之间的可调插值。

本文进一步指出，深度网络中经验观测到的重尾权重谱和梯度噪声统计本身就是非广延性特征，从而将现代学习动态纳入 $q$-统计的范畴。最后，讨论了方法论陷阱、与信息几何及 $q$-指数族的关系，以及开放方向，主张应将 $q$ 视为可学习的归纳偏置，而非固定超参数。

Consistency Has a Computable Blind Spot: A Commutation Theory of Label-Free Reliability for Vision-Language Figure Reading（一致性存在可计算的盲区：面向视觉-语言图表阅读的无标签可靠性交换理论）

核心观点与重点提炼：

1. 问题提出：视觉-语言模型的无标签可靠性基于不变性（扰动输入后，忠实模型的答案不应改变）。该方法存在一个已知盲区——系统性的误读可能逃逸扰动而被错误认证，本文证明该盲区是可计算的（而非仅存在）。

2. 核心理论——交换关系：当且仅当编辑与误差“可交换”（commute）时，误差对编辑不可见。因此，一套编辑无法覆盖的误差构成其“联合中心化子”（joint centralizer），该集合随编辑增加而缩小，且可显式写出而非猜测。

3. 互补策略——等变性（Equivariance）：编辑图表数据时，正确答案必须按可计算量变化。两个匹配的编辑对仿射读取误差可证完备；但任何交换编辑集对标签置换均不完备，而循环重标定（cyclic relabeling）可弥补大部分差距。

4. 方法实例化：将理论落地为等变-一致性评分（Equivariance-Consistency Score）——一种无标签、免训练检测器；并发布REND-EQUIV数据集，在同一数据上配对匹配的不变性与等变性集合。

5. 实验验证：预测排序在三个模型及手工标注群体上成立（且排除了选择循环性）；第二类不变性家族方法证实盲区属于“关系”本身而非具体实现；循环重标定在真实配对样本上带来预期增益。

6. 理论推广：同一特性解释了分类器变形测试文献中报告的结果反转——可检测性是“关系+故障类别”的联合属性，而非关系单独决定。

When Compression Scores Cannot Decide: Information Boundaries for Group-Robust LLM Pruning（当压缩分数无法决断：面向群体稳健的大语言模型剪枝的信息边界）

核心发现：稳定的压缩分数仍可能选出更差的模型。在密集实验中，分裂半可靠路径二次分数预测了16.1%的性能提升，但所选端点的表现比两个对照组差6.0–7.7%。当部署关注最差供给群体时，一个压缩统计量能够证明的结论有限。

理论框架：每个统计量被视为信息接口——其观测结果保留了兼容端点风险表的纤维（fiber），且只有在该纤维上顺序固定的结论才是可识别的。锥体（cone）与纤维恒等式量化了剩余不确定性；匹配观测可逆转池化矩、群体局部矩和参考路径曲率的端点顺序。序列组合增加一个状态变量：各群体风险到当前最大值的松弛量。该向量决定所有无限制的单步响应，而边际条件在相对漂移有界路径上保持活跃群体不变。

实验验证：实验遵循相同阶梯结构。在三个稠密大语言模型上，早期保留分配将最差群体的困惑度膨胀降低12.6–20.9%；目标匹配的完整菜单选择相比参考方法提升2.7–8.0%。在OLMoE的全部16个路由层上，池化端点刷新相比最佳静态分数，将留出最差群体教师KL散度降低15.8%。计算匹配的硬最大轨迹最终比池化方法差32.7%，且两种自适应轨迹均未改善超额NLL。

结论：局部证据可以收窄菜单，完整端点对菜单进行排序，而多步声明还需对演化的活跃面和未来候选进行控制。

核心问题：细粒度能源消耗数据对需求预测、需求响应规划和电网可靠性评估至关重要，但由于隐私和共享限制难以获取，因此合成能源数据生成备受关注。现有方法能再现整体消耗分布和周期性模式，却常平滑或低估极端天气、基础设施故障和行为变化引发的异常事件——因为这些事件稀疏、时空局部化，且受地理邻近性和区域属性等异构依赖影响。

方法创新：提出SynEnergy，一个两阶段扩散框架用于保留异常的能源数据生成。第一阶段HG-ASL（基于异质图的异常语义学习）：通过联合建模城市区域间的空间与属性依赖，从稀疏残差结构中提取区域特定的异常语义。第二阶段AS-Diff（异常语义引导扩散）：将学习到的异常语义注入去噪过程，在保留异常模式的同时生成真实消耗序列。该设计支持单区域可控生成，并可自然扩展到全市范围。

实验结果：在4个真实能源数据集上与11个通用及能源专用生成基线对比，SynEnergy将异常保留保真度平均提升12.21%，下游任务质量提升2.96%，同时总体生成保真度与基线持平。

VLAGuard: A Framework for Evaluating and Mitigating Physical Attention Hijacking in Vision-Language-Action Robots within Wireless Sensor Networks（VLAGuard：无线传感器网络中视觉-语言-动作机器人物理注意力劫持的评估与缓解框架）

核心内容总结：

1. 研究背景与问题：将视觉-语言-动作（VLA）机器人部署为无线传感器网络（WSN）中的移动边缘节点，面临物理对抗性威胁。本文聚焦于一种关键漏洞——策略关键的动作到视觉注意力劫持。

2. 攻击模块（VASA）：提出压力测试模块——视觉运动注意力引导的语义攻击（VASA），利用可打印贴片严重干扰机器人动作条件交叉注意力。

3. 防御模块（APFT）：提出注意力保护微调（APFT）防御方法，稳定时空注意力并强制几何一致性，且零推理开销。

4. 实验效果：在仿真与真实环境中验证显著鲁棒性提升：APFT将LIBERO仿真中OpenVLA的失败率从100.0%降至25.9%；在2,000次真实世界试验中，面对严重贴片攻击，平均成功率从23.0%提升至67.4%。

5. 结论：保护注意力通路对于提升传感器网络中VLA驱动的边缘节点的鲁棒性至关重要。

SkillHEX: Improving Agent Skills via Hypothesis-Driven Autonomous Exploration and Exploitation（SkillHEX：通过假设驱动的自主探索与利用提升智能体技能）

核心问题：现有的智能体技能维护依赖人工，成本高、无法规模化且与实际需求脱节。实际部署需要在测试时自主、按需地进化技能，但受限于有限的交互预算和缺乏训练/验证集，这带来严重的稀疏奖励问题——结果中混杂多个潜在失败原因，导致现有仅贪心优化单一技能的算法容易陷入“利用陷阱”，早期错误诊断会浪费有限的尝试机会。

方法创新：提出SkillHEX闭环框架，结合假设驱动自验证与证据引导树搜索。它将可证伪的失败假设转化为可执行测试，在不额外增加环境交互的情况下产生诊断性证据作为稠密奖励；该证据引导对技能修订分支的搜索，动态平衡对已有修正的利用与对合理替代方案的探索。

关键结果：在SkillsBench的87个任务上，SkillHEX优于现有自进化方法，在使用GPT-5.3-Codex和Claude Opus 4.7、五次迭代预算下，平均通过率分别达到55.9%和57.9%。

VaRS-Doc: Interpretation-Aware Variant Representations via Latent Self-Probing for Visual Document Retrieval（VaRS-Doc：基于潜在自探的语义变体表示用于视觉文档检索）

核心问题：视觉文档检索中，传统方法采用“离线编码+晚期交互”架构，将文档预先编码为固定表示。但同一文档内容会因查询意图不同而产生不同语义解读，固定表示无法捕捉这种多样性；若等查询到来再编码，则检索延迟过高。

方法创新：提出VaRS-Doc框架，在文档编码阶段让模型主动探索多种潜在的语义变体表示（latent variant interpretations），同时保持晚期交互检索的高效性——每个查询可自适应选择最匹配的表示。配套两阶段训练策略，鼓励模型学习互补的语义解释，避免退化为单一主导表示。

实验结果：在视觉文档检索基准上取得SOTA性能，有效解决了“查询无关的文档编码”与“查询特定的检索需求”之间的不匹配问题。
