HLSmith: An Expert-Guided Agentic Framework for C/C++-to-HLS Translation（HLSmith：面向C/C++到HLS转换的专家引导智能体框架）

该论文提出HLSmith，一个专家引导的智能体框架，用于将C/C++程序转换为优化的高综合（HLS）加速器设计。核心要点如下：

1. 问题背景：特定应用FPGA加速器虽性能/能效卓越，但开发成本高、周期长；即便使用HLS仍需深厚硬件专业知识；大语言模型（LLM）缺乏硬件直觉和程序性知识，难以可靠地将C/C++转换为高性能HLS设计（无法识别有效架构、遵循专家优化流程、跨内核一致应用硬件变换）。

2. 方法组成：HLSmith结合三个组件——HLS优化专家库（编码带守卫的变换配方、适用条件及不安全案例）；阶段式反馈驱动的编排流程（模拟专家开发实践，引导智能体完成综合、瓶颈分析、优化）；工具接地模型自适应流水线（将商业前沿模型的优化轨迹转换为微调开源LLM的训练数据）。

3. 核心结果：在PolyBench基准上对比领先的ChatHLS框架，HLSmith取得几何平均4.24倍加速，且所有基准均产生功能正确的设计（软件和RTL仿真），而ChatHLS仅57%设计有效。此外，HLSmith在使用商业前沿模型和开源模型时分别达到最高252倍和138倍加速。

BALANCE: Hybrid Autoregressive-Speculative LLM Inference in Wireless Edge Networks（BALANCE：无线边缘网络中的混合自回归-推测式大语言模型推理）

边缘推理是下一代移动网络中提供大语言模型（LLM）推理服务的一种有前景的范式。LLM推理主要依赖两种方法：自回归解码（AD）顺序生成输出token，导致较长延迟；推测解码（SD）通过使用小语言模型（SLM）生成多个草稿token供LLM验证来加速推理，但会带来额外内存成本。由于这种延迟-内存权衡，在有限边缘计算资源下，单一方法均无法高效服务异构需求的用户。为此，我们提出一种用于边缘LLM推理的混合自回归-推测推理框架（BALANCE）。在BALANCE中，边缘服务器同时托管SLM和LLM，将每个用户分配给AD或SD，并同时执行两种模式。为最大化服务用户数，我们构建了一个任务吞吐量最大化问题，在用户延迟要求和服务器内存约束下，联合确定用户调度以及AD与SD之间的计算资源分配。由于该问题为NP难问题，我们开发了一种多项式时间算法，将原问题转化为两个子问题，并获得具有恒定近似保证的次优解。实验表明，BALANCE始终优于传统AD和SD，并显著提升任务吞吐量。

ICO: Enhancing Semantic-Shift Jailbreaks via Iterative Context Optimization（ICO：通过迭代上下文优化增强语义转移越狱）

核心要点总结：

1. 研究背景与问题：基础模型虽表现优异但存在安全漏洞。语义转移越狱（semantic-shift jailbreaks）是一种新兴攻击范式，通过用良性替代词替换有害词，并利用上下文信息诱导模型将替代词重新解读为有害概念，从而绕过安全机制。但现有方法的有效性有限。

2. 关键发现：现有方法忽视了下文的语义转移能力。研究表明，不同上下文在诱导语义转移方面能力差异显著——语义转移能力越强的上下文，越能引导模型恢复有害含义并实现成功越狱。

3. 方法创新：基于上述发现，作者系统识别并提炼了有效上下文的特征，提出了一种黑盒、上下文感知的语义转移越狱框架——迭代上下文优化（ICO）。每一轮迭代中，ICO利用这些特征和目标模型的反馈来优化上下文。

4. 实验结果：在三个数据集和八个目标基础模型上的大量实验表明，ICO持续优于八种最先进的基线方法，平均攻击成功率达到74.6%。

深度学习近年取得巨大成功，离不开高质量、良好标注的训练数据。然而，现实应用常常无法满足这一要求。弱监督学习旨在利用不完整、不精确或不准确的监督信息训练出准确模型。本章讨论该领域的最新进展，包括新监督范式、放宽后的假设以及实用解决方案。首先，我们提出一个新的弱监督二分类问题——置信度差分类，并设计了一致性方法予以解决；其次，研究互补标签学习这一弱监督多分类问题，我们提出的方法建立在比现有一致性方法更宽松的数据生成过程假设之上；最后，介绍一个针对部分标签学习的评估框架——作为另一类流行的多类弱监督学习问题，该框架旨在推动该领域算法评估的公平性与现实性。

MoEGen: Mixture-of-Experts for Instance-Adaptive LoRA Generation（MoEGen：面向实例自适应LoRA生成的混合专家方法）

核心观点：本文提出一种新型参数高效微调（PEFT）框架MoEGen，将基于混合专家（MoE）的PEFT从“专家选择”范式转变为“专家条件参数生成”范式。传统MoE-PEFT方法需为每位专家显式存储一个完整LoRA适配器，导致存储量随专家数线性增长且只能固定适配预定义的专家池；MoEGen则不再为每位专家存储独立LoRA模块，而是将每位专家表示为一个小型可学习向量（即“专家编码”），通过路由输入到这些向量上，并利用其加权组合来调节一个轻量级超网络，从而生成输入特定的低秩更新。该设计解耦了专家容量与适配器存储，同时实现实例条件的自适应。

实验结果：在八个常识推理基准上，MoEGen跨三个骨干模型一致优于强静态基线和MoE-PEFT基线；在医学与法律领域的联合域适应中也表现优异。

Global Attention-Fused Image Cropping with Attention-Guided and Global-Aligned Crop Evaluator（全局注意力融合的图像裁剪：基于注意力引导与全局对齐的裁剪评估器）

核心问题：现有图像裁剪方法主要聚焦显著区域，对图像主要组件间的全局关系敏感性不足。

方法创新：提出GAFIC框架，包含两个关键模块——注意力引导特征融合（AGFF）与全局对齐裁剪评估器（GACE）。AGFF聚合局部区域重要性，构建同时捕捉图像结构与局部细节的全局表征；GACE将候选裁剪特征与该全局表征对齐，使评估对边界变化保持敏感。

训练策略：组合三种跨尺度排序损失，获得准确且稳定的裁剪评分。

实验结果：在GAIC和CPC数据集上，GAFIC优于现有方法，尤其在准确性和稳定性方面表现突出。

关键区别：与像素级重定向方法（如接缝裁剪、修复、扩散合成）不同，GAFIC不合成或修改保留像素，而是直接从源图像中选择美学上更优的裁剪区域，适用于像素完整性和高效批量处理重要的场景。

How Much Reconstruction Does Quantum Machine Learning Need? Late Fusion of Independently Trained Quantum Subcircuits（量子机器学习需要多少重构？独立训练量子子电路的晚期融合）

核心观点：电路切割允许大型量子神经网络在小型设备上以独立子电路形式运行，但通过重构重建其输出会产生随切割数量指数增长的经典采样开销——这是此前工作的主要运行时成本。

关键发现：本文提出用晚期融合替代重构：每个子电路独立训练和测量，由一个小型经典头部组合其输出——这是一种源自多模态学习的线性成本决策级组合。

方法论创新：引入量子度旋钮（quantumness dial，可调重构预算，从纯融合插值到完全重构）和切割纠缠诊断指标，用于指示任务需要多少重构（104次运行中Spearman ρ=0.59）。

实验结果：在合成和标准数据集上，独立训练的晚期融合在受控扫描的每个点及每个经典基准上，准确率与完全重构差距在0.04以内，但成本指数级降低；同时对噪声（shot噪声和设备噪声）的鲁棒性显著更强。受控纠缠数据实验定位了融合必须失效的边界。

重要声明：不声称相对经典机器学习有优势——与近期基准测试一致，量子在这些数据集上无精度优势。晚期融合因此是电路切割QML中重构的高效、抗噪、自表征替代方案。

1. 问题背景与挑战：扩散模型虽生成能力强，但其最大似然训练目标仅关注重建数据分布，难以对齐特定偏好。基于强化学习（RL）的偏好对齐方法受奖励稀疏性限制——由于单一奖励难以支撑优化，现有RL方法通常将最终奖励反向传播至所有时间步。然而去噪过程具有阶段性，各阶段语义和可控性不同。跨步骤重复最终奖励会导致时间目标失配，引发奖励捷径（reward hacking）；同时奖励回填使各时间步获得相同奖励，无法区分动作优劣，削弱优化效果。

2. 核心方法（SGPO）：提出阶段引导的逐步优化（SGPO），联合利用信噪比和语义变化识别生成阶段，自适应分配阶段特定目标。具体策略为：早期阶段去噪混沌且与最终奖励关联弱，应优先退出混沌状态；中期阶段潜变量转向稳定结构，最终奖励与生成行为对应性增强，在优化最终奖励的同时探索多样性，避免过早收敛至单一模式；晚期阶段核心结构基本固定，偏好优化主要放大局部细节，存在过拟合风险，因此侧重稳定收敛以防止质量退化。

3. 实验结果：16组对比实验验证SGPO的有效性，生成质量平均提升26.7%，收敛速度提高36.7%。

Any-OPD: Heterogeneous On-Policy Distillation for Flow-Matching Models via Representation-Space Bridging（Any-OPD：通过表示空间桥接实现流匹配模型的异构同策略蒸馏）

核心问题：传统同策略蒸馏（教师纠正学生自生成样本）预设师生模型共享相同语言——即相同的VAE潜变量、匹配的架构和统一的时间步网格。当教师与学生来自不同模型家族时（如最强教师与待部署学生分属不同架构），这些条件全部失效：教师潜变量无法作为外部坐标系中的训练目标；对随机重绘局部细节的教师进行逐像素损失会导致模糊或发散；时间步索引在不匹配的调度中失去意义。

方法创新：Any-OPD是首个适用于任意潜空间流匹配生成器对的同策略蒸馏框架。它将教师视为纯黑盒采样器，仅在一个点上连接两模型：通过冻结的、模型无关的视觉表征比较两者独立解码的输出，从而绕开对潜变量、特征或架构的所有假设。轨迹对应通过匹配连续噪声水平（而非步索引）恢复；简短的锚定阶段将教师样本通过学生自身VAE重新编码，确保同策略梯度衡量的是样本质量而非域不匹配。

实验结果：将12B的FLUX.1-dev蒸馏至2.5B的SD3.5-Medium，Any-OPD将学生模型的PickScore从0.846提升至0.884，HPSv3从9.12提升至10.97，在仅为教师五分之一规模下达到与教师相当的性能；相比之下，直接潜回归训练完全失败。

Fast Object Removal Attacks on Safety-Critical Video-based Perception Systems（针对安全关键型视频感知系统的快速对象移除攻击）

摘要总结：本文针对基于视频的智能交通系统（ITS）提出了一种新颖的攻击模型及端到端框架，实现近实时、有针对性的目标对象移除攻击。攻击流程包含四个阶段：逐帧定位目标、从先前帧提取连贯补丁、利用上下文感知的Alpha合成进行混合、以及重建被攻击帧。在南卡罗来纳州互联车辆测试平台（SC-CVT）交叉路口的实验表明：重建帧与原始帧全局相似度高（帧级PSNR高于40 dB，SSIM高于0.996）；基于YOLO的检测器下，攻击可将对象检测率降低高达97.59%，帧级攻击成功率达94.48%；在GPU硬件上每帧平均执行时间为0.074至0.172秒，具有近实时性能；多种预训练篡改检测模型的取证评估显示其难以区分重建帧与真实帧。核心结论：视频感知系统易受隐蔽的对象移除攻击，此类攻击可通过降低对象可检测性来削弱安全关键应用（如基于视觉的行人安全系统）的性能，研究结果有助于制定针对此类对抗性攻击的缓解策略。
